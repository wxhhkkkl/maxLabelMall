# 行业方案总览页面

用于替代当前 `/solutions`（用户称 `/solution`）的入口页。当前交付为设计图，未修改生产页面或部署。

## 页面结构

1. 品牌导航 + 首屏「让标签，成为业务的连接点」，聚合打印机、包装箱、吊牌和食品标签，呈现行业共用的标签能力。
2. 十大行业入口：桌面五列两行，包含行业场景、简短任务描述、标签类型、详情入口。设计包含行业搜索及分类筛选，需在开发时实现交互。
3. 通用方案方法：梳理场景 → 设计标签 → 匹配打印 → 验证流程。
4. 标签样例：用库位标、商品吊牌和批次效期标解释识别商品、关键变量、后续作业。
5. 定制方案咨询 + 网站页脚。

## 视觉与落地

沿用品牌蓝 #2E7CD6、深蓝标题 #0C2148、浅蓝背景 #F3F8FF、14px 圆角卡片。主入口页重在导航和理解，详情页承接行业痛点与具体流程。移动端建议行业入口改为两列，流程改为纵向，分类胶囊可横向滚动。

图中文字、日期与条码为视觉示意；正式开发时文字使用可编辑 HTML，沿用项目实际 logo、导航和组件。功能描述需结合实际产品能力确认。

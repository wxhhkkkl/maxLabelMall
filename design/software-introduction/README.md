# MaxLabel 软件介绍页 · 设计稿

首屏主题：**让标签设计极致简单**。

## 视觉与内容

- 延续商城现有白色导航、品牌蓝、深蓝底部和宽松留白。
- 首屏居中大标题，第二行「极致简单」用品牌蓝强调。
- 软件窗口采用朦胧预览，中央清晰展示「敬请期待」与「MaxLabel · 开发中」。
- 设计体验区的界面同样朦胧处理，标签成品与网页文字保持清晰。
- 数据区使用涂料生产企业示例，以产品、色号、批次三列数据对应水性底漆、水性面漆、罩光清漆三张标签，属于概念示意。
- 最后的三个例子为涂料产品标、服装吊牌、仓储库位标，使用清晰的实物场景展示不同应用。
- 页面收尾再次呈现「敬请期待」，不放下载、付费或试用期限承诺。

## 页面顺序

1. 首屏：让标签设计极致简单。
2. 简单，从第一张标签开始：设计、数据、打印三项体验方向。
3. 把想法，放到标签上：朦胧编辑器与标签成品。
4. 一份数据，多张不同的标签：涂料企业表格字段与产品标签输出示意。
5. 小小标签，也值得认真设计：涂料产品标、服装吊牌、仓储库位标三种实物标签应用。
6. 更简单的标签设计，正在到来：开发中提示。
7. 沿用现有底部。

### 0.1 应用迁移

```bash
# 二选一
python scripts/apply_003_filter_dimension.py --file yudao-cloud/sql/mysql/014-maxlabel-member.sql
# 或
mysql -u<user> -p <db> < yudao-cloud/sql/mysql/014-maxlabel-member.sql
```

迁移包含：5 张表、字典（如需要）、`system_menu` 页面与按钮权限（幂等插入）。

### 0.2 准备会员商品与计划

1. 管理端 → 商品管理：建**一个** SPU「MaxLabel 会员授权」，配送方式选**虚拟商品**；
   建两个 SKU：月卡、年卡，**价格 > 0**。不要建第二个会员 SPU（系统会拒绝多 SPU 映射）。
2. 管理端 → 会员中心 → **会员授权商品**：把两个 SKU 分别映射为 `periodMonths=1/12` 并启用。
   保存时会校验：SPU 仅虚拟商品、当前没有其他启用 SPU、SKU 价格 > 0。
3. 确认 `GET /app-api/product/subscription-plan/list` 能返回两条（匿名可访问）。

### 0.3 桌面端配置

在桌面端设置中填：

- 商城地址：本机联调填 `http://localhost:5173`（仅回环允许 HTTP；远程必须 HTTPS）
- 租户：`162`
- 打印上报开关：默认开

> 商城地址为空时，所有商城/云模板入口显示"未配置商城地址"，本地编辑与打印不受影响。

## 2. 手工验收场景

### 2.1 US28 登录（SC-076 / SC-083）

1. 桌面端点「登录」→ 弹出商城登录窗口 → 用验证码或密码登录。
2. 预期：窗口关闭，桌面端显示脱敏手机号与订阅状态；重启桌面端仍为登录态。
3. 关闭网络/退出登录 → 本地新建模板、编辑、打印**全部可用**。
4. 令牌过期：把 access token 改为无效值，下一次云操作应自动刷新或提示重新登录，
   **未保存文档不丢失**。
5. 从桌面端打开商城 → 顶栏已是登录状态，**不要求二次登录**。

### 2.2 US29 购买与开通（SC-077 / SC-078 / SC-085 / SC-087）

1. 未订阅账号：桌面端「购买会员」→ 打开 `/membership` → 选月卡 → 商品详情 → 结算
   （**不出现收货地址**）→ mock 支付成功。
2. 预期：桌面端一次刷新/重开内显示有效订阅；后台会员详情「订阅」页签出现一段周期，
   来源订单号正确。
3. 未到期再买年卡 → 新段 `start = 原到期日次日 00:00`，`endDate = start + 12 个月`（最后有效日），
   `end_time = endDate 次日 00:00`。
4. 到期日边界：把当前段改成 `end_time = 明天 00:00`（到期日 = 今天）→ 仍显示有效；
   改成 `end_time = 今天 00:00`（到期日 = 昨天）→ 过期。
5. 过期后：
   - 桌面端显示「已过期」；
   - 可浏览/下载自己的模板与共享模板；
   - 上传、覆盖、提交共享返回 403（SC-087）；
   - 本地编辑/打印与打印上报**照常**。

### 2.3 US30 云端模板（SC-079）

1. 登录并订阅有效 → 上传一个 `.msdx`。
2. 预期：云端列表出现；换一台设备登录同账号可下载并打开打印；
   另一个账号**看不到**（列表与按 id 读取都不可见）。
3. 上传含数据库连接口令的模板 → 下载后口令字段为空。
4. 同名再传 → 桌面端询问覆盖/另存。
5. 超过 16 MB → 明确报错，本地文件仍在；超过 1000 个或 256 MB → 明确配额提示。
6. 删除云端模板 → 本地文件仍在；若已共享，共享条目一并消失。

### 2.4 US31 共享模板（SC-080）

1. 会员提交共享 → 状态「待审核」，其他会员**看不到**。
2. 运营后台「共享模板审核」→ 通过 → 另一会员刷新 ≤ 1 分钟可见并可下载。
3. 下载后修改并保存 → 原共享条目与发布者模板**不变**。
4. 运营驳回并填原因 → 会员端可见原因；重新提交后回到待审核。
5. 运营下架 → 会员刷新后列表不再出现；已下载副本仍可用。
6. 检查共享正文：无数据库口令、无 RFID 读写口令、`datasets[*].rows` 为空。

### 2.5 US32 商城入口

1. 桌面端「商城」→ 打开门面站（应用内窗口），已登录。
2. 加购一件实物商品 → 结算需地址；加购纯虚拟商品 → 不需地址。
3. 支付成功 → 商城订单列表可见；在浏览器登录同账号也能看到同一订单。
4. 价格/库存/优惠以服务端为准（改价后桌面端刷新即变）。

### 2.6 US34 打印记录（SC-082）

1. 登录、上报开关开启 → 正常打印一次。
2. 预期：后台会员详情「打印记录」出现 1 条；字段与桌面端本地日志一致；
   **无数据快照**。
3. 测试打印 → **不产生**记录。
4. 关闭设置开关 → 再打印 → 后台不新增，本地日志仍有。
5. 断网打印 → 联网后后台**不补**该条（Q49），本地日志仍在。
6. 同一 `recordUid` 重复上报 → 后台只有一条。

### 2.7 管理端权限（SC-081 / SC-084）

1. 用有权限的账号：会员列表显示**订阅状态与到期时间**（无订阅/已过期/有效三种）；
   进入会员详情 → 三个新页签均可打开，数据按会员隔离。
2. 用无 `member:shared-template:audit` 的账号：审核按钮不可见，直接调接口返回 403。
3. 跨会员：A 的模板/打印记录不会出现在 B 的详情；C 端按 id 读取他人模板返回"不存在或无权限"。

### 2.8 回归（SC-083 / SC-086）

1. 既有授权码：升级后仍能激活、复检、显示到期日；本地功能不变。
2. 打印流水线：驱动/命令两种模式、预览、导出与升级前一致。
3. 既有商城订单：普通实物订单的下单/支付/发货/退款逐字段不变。
4. 未登录用户：本地模板库、打印、导出全部可用。

## 3. 显式不验证（及理由）

| 项 | 为什么不验证 |
|---|---|
| 真实微信扫码端到端 | 需要公众号授权域名与真实微信账号；桌面端只是承载门面站登录窗口。开发环境用验证码/密码登录，扫码走商城既有 e2e（`WechatQrPanel`） |
| 真实支付渠道扣款 | 涉及资金；使用 `mock` 渠道验证回调链路 |
| 短信真实下发 | 有成本与频控；固定验证码 `9999` |
| 高并发支付回调压测 | 幂等由数据库唯一键与单测覆盖；压测不在本期 |
| 0 元会员订单 | 产品规则要求会员 SKU 价格 > 0；0 元单不触发 `updateOrderPaid`，本期不支持（R49） |
| 旧「云数据库导入」 | 随旧云账户下线（Q52/R57）；**需所有者确认**，确认前不要删除代码，只隐藏入口 |
| 打印记录跨年大数据量 | 永久保留（Q53）；本期只验证分页与索引，不做容量压测 |
| 管理端 UI 全量视觉回归 | 沿用既有页面组件；只验证功能与权限 |

## 4. 关键日志与排障

| 现象 | 先看 |
|---|---|
| 桌面端请求 400「租户标识未传递」 | 是否带 `tenant-id: 162` |
| 登录窗口拿不到令牌 | 窗口 origin 是否等于配置的商城地址；localStorage 键名是否仍是 `MAXLABEL_ACCESS_TOKEN` |
| 支付成功但订阅没开通 | `pay_notify_task` 是否成功回调 `/trade/order/update-paid`；订单项 SKU 是否有计划映射；唯一键是否已存在 |
| 续费没有顺延 | `member_subscription` 最新 `start_time` 是否 = `max(今天, 上段 end_time 的日期) 00:00`（不要再 +1 天），`end_time` 是否为最后有效自然日的次日 00:00 |
| 模板上传 403 | 订阅是否有效；`member_id` 是否本人 |
| 共享列表为空 | `audit_status` 是否为 1；是否被下架 |
| 后台按钮不显示 | `system_menu` 是否插了对应 `permission` 行 |
| 打印记录缺失 | 上报开关、是否登录、是否测试打印、是否断网 |

## 6. 安全复核（2026-10-20，代码层）

| 项 | 结论 |
|---|---|
| 令牌存储 | `safeStorage` 加密，按商城地址隔离；安全存储不可用时拒绝明文落盘 |
| 令牌泄漏面 | 不进日志、标题、错误信息；刷新后写回商城窗口的 localStorage |
| 商城窗口 | 精确 origin 校验；`contextIsolation`/`sandbox`；无 preload；拒绝新窗口 |
| 私有模板 | 正文存自有表，不经 `infra_file` 公开 URL；下载走鉴权接口并校验归属 |
| 共享副本 | 服务端二次清洗：数据库口令、RFID 读写/销毁口令、数据集行 |
| 打印上报 | 白名单字段，不含 `dataSnapshot`/模板正文/连接信息 |
| 请求校验 | `tenant-id`/`terminal`、UUID、大小、配额、状态白名单；服务端按登录会员取归属 |
| 待人工复核 | 生产域名 HTTPS、角色权限分配、真实支付/微信链路（见 §3） |

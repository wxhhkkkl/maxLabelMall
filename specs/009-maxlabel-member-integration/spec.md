## 背景与问题

今天，这两套系统**各有一半，彼此不认识**：

- **桌面端有一半「云」，但不是商城的云。** `maxlabel` 已有云账户与云模板
  （`app/src/main/cloudRepository.ts`，接口 `/api/auth/*`、`/api/cloud/templates*`），
  也有授权码激活（`app/src/main/license.ts`，`/api/license/activate|check`，按机器码绑定）。
  但它连的是**另一套 FastAPI 服务**，与商城的会员、订单、支付无关。
  启动页的「标签商城 / 签赋会员服务」仍指向旧站 `www.360code.com`（`app/src/renderer/src/pages/StartPage.tsx`），
  是静态外链，不是商城。
- **商城有一半「会员与交易」，但没有 MaxLabel 的身份与数据。** yudao 的会员体系
  （`member_user`、手机号验证码/密码/微信扫码登录，见 `specs/005-wechat-scan-login/spec.md`）
  与交易链路（购物车 / 结算 / 支付 / 虚拟商品，见 `specs/007-virtual-goods/spec.md`）都是现成的，
  **但没有订阅实体**（没有会员有效期表），**也没有标签模板与打印记录实体**
  （`storefront/src/views/TemplateCenterView.vue` 自述"yudao 没有标签模板实体，本期不调任何接口"）。
- **后台会员详情**已有「订单管理」页签（`yudao-ui-admin-vue3/src/views/member/user/detail/`），
  **没有订阅、模板、打印记录**三个页签。

结果：客户买了一台软件却**没有商城的会员身份**；装了软件又**不知道自己的会员还剩多久**；
上传到云端的模板**不属于任何可运营的会员**；打印行为**完全不可见**（桌面端日志只在本机，
`specs/012-print-history/spec.md` 明确写了"不同步云端"）。

本特性要做的，是把**一个会员身份、一份订阅、一套模板库、一份打印记录**在两端打通。

## Clarifications

### Session 2026-10-20

- **Q48 会员授权（订阅）如何生效、如何约束？**（2026-10-20 所有者拍板）
  → A: **支付成功即自动开通**；订阅**绑定会员账号、不绑定设备**，同一账号可在多台设备登录；
  **不新增桌面功能限制**，订阅只作为会员身份与云端服务权益凭证，过期只提示并给续费入口。
  续费从原到期日顺延。
  背景：桌面端现有授权码按机器绑定且不限制功能（E7）；新增功能锁会改变已发布版本的行为，
  故选"只标识、不锁功能"的最小改动口径。

- **Q49 打印记录上报的范围与开启方式？**（2026-10-20 所有者拍板）
  → A: **登录后自动上报结构化字段**（时间、模板名、打印方式、数量、副本、状态、打印机），
  **不含 `dataSnapshot`、数据库连接信息或标签中的客户业务数据**；桌面端设置中**默认为开**，
  用户可关闭。后台可按会员逐条查看。
  背景：本地日志含数据快照（E9），可能涉及客户业务数据；本口径在"后台可见"与"不搬业务数据"之间取平衡。

- **Q50 平台共享模板的来源与审核？**（2026-10-20 所有者拍板）
  → A: **运营审核后公开**。会员发布为"提交审核"（待审核），运营在后台审核通过后才进入共享库；
  驳回需填写原因。会员可随时取消发布，运营可随时下架。
  背景：共享库面向所有会员，内容质量与合规需要有人负责。

- **Q51 会员授权按什么产品结构售卖？**（2026-10-20 所有者拍板）
  → A: **单一会员产品 + 可选周期**（例如 1 个月 / 1 年），同一产品下按周期定价；
  本期**不做**多档会员（专业版/企业版）与档位权益。档位如后续需要，再单独决策。

- **Q52 旧云账号与已上传的云端模板怎么处理？**（2026-10-20 所有者拍板）
  → A: **不迁移**。更新后桌面端**只使用商城会员这一套新体系**：旧云账户（邮箱+密码）登录入口
  与旧云模板入口停用，旧云端模板不导入；旧服务里的数据不删除，但桌面端不再连接。
  既有授权码仍按 FR-229 继续有效。

- **Q53 后台打印记录保留多久？**（2026-10-20 所有者拍板）
  → A: **永久保留，不做自动清理**；后台必须分页与按时间筛选，避免数据量大时拖慢页面。

- **Q54 订阅是否作为云端能力的闸门？**（2026-10-20 所有者拍板）
  → A: **对写入设闸、对读取不设限**。上传、覆盖、发布到共享库需要有效订阅；
  过期后仍可浏览与下载自己的模板及共享模板；打印记录照常上报；本地编辑与打印不受影响。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 用商城会员账号登录桌面端 (Priority: P1 · US28)

客户在 MaxLabel 桌面端点「登录」，用他在商城的账号（手机号验证码 / 密码 / 微信扫码）登录。
登录成功后，桌面端显示他的会员身份与订阅状态；重启软件仍保持登录，直到他主动注销。

**Why this priority**：这是本特性所有其他故事的地基 —— 没有统一身份，订阅、模板归属、
打印记录归属都无从谈起。

**Independent Test**：用一个已有商城账号在桌面端登录 → 断言桌面端显示脱敏账号标识与订阅状态；
重启桌面端 → 仍为登录态；点注销 → 回到未登录且云端功能不可用。

**Acceptance Scenarios**：

1. **Given** 桌面端未登录且能访问商城，**When** 选择手机号验证码登录并输入正确验证码，
   **Then** 登录成功，桌面端显示脱敏手机号与订阅状态
2. **Given** 已在商城网页登录同一账号，**When** 从桌面端进入商城/模板库，**Then** **不要求二次登录**
3. **Given** 已登录，**When** 重启桌面端，**Then** 自动恢复登录态
4. **Given** 已登录，**When** 令牌失效或被服务端注销，**Then** 桌面端提示重新登录，
   且**未保存的本地文档不丢失**
5. **Given** 未登录，**When** 使用本地编辑与打印，**Then** **功能不受任何影响**（回归 E12）

---

### User Story 2 - 在桌面端购买并开通会员授权 (Priority: P1 · US29)

客户在桌面端看到「会员已过期 / 未订阅」的提示，点「购买/续费」，进入商城选择会员授权商品并付款。
付款成功后，他的订阅立即生效或顺延，回到桌面端即可看到新的到期日。

**Why this priority**：这是本次商业化闭环的核心；没有它，登录只是换了个头像。

**Independent Test**：用一个未订阅账号从桌面端进入商城 → 购买会员授权 → 支付成功 → 断言桌面端
显示有效订阅与正确到期日；再次购买同一商品 → 到期日顺延一个周期。

**Acceptance Scenarios**：

1. **Given** 未订阅会员，**When** 从桌面端进入商城购买会员授权并完成支付，
   **Then** 订阅变为有效，桌面端显示到期日
2. **Given** 订阅仍在有效期内，**When** 再次购买同一会员商品并支付成功，
   **Then** 到期日 = 原到期日 + 新购周期（**不清零、不覆盖**）
3. **Given** 结算页只含会员授权商品，**When** 结算，**Then** **不要求收货地址**（复用 E3）
4. **Given** 支付成功，**When** 返回桌面端，**Then** 在最迟一次刷新/重开内看到新状态，
   **无需运营手工开通，也无需输入激活码**
5. **Given** 订阅已过期，**When** 打开桌面端，**Then** 明确显示「已过期」和续费入口，
   且**本地功能仍可用**；云端仍可浏览与下载，但**上传与发布被拒绝**

### User Story 3 - 上传本地模板到云端 (Priority: P2 · US30)

已登录会员把本地设计好的标签模板上传到云端。他在云端看到自己的模板列表，可以下载回来、
覆盖更新或删除；模板只属于他自己。

**Independent Test**：登录后上传一个 `.msdx` 模板 → 云端列表出现该模板 → 换一台设备登录同账号 →
能下载并成功打开打印；换个账号登录 → **看不到**该模板。

**Acceptance Scenarios**：

1. **Given** 已登录并打开一个本地模板，**When** 选择「上传到云端」，
   **Then** 云端出现该模板，名称、尺寸、对象与本地一致
2. **Given** 模板含数据库连接配置，**When** 上传，**Then** 密码等敏感字段**不被上传**（E8）
3. **Given** 已上传模板，**When** 再次上传同名模板，**Then** 系统明确询问是覆盖，还是另存为另一个模板
4. **Given** 已登录，**When** 删除某个云端模板，**Then** 云端列表移除，本地文件不受影响
5. **Given** 未登录，**When** 点「上传到云端」，**Then** 引导登录，**不静默失败**

### User Story 4 - 使用平台共享模板库 (Priority: P2 · US31)

会员把自己的某个模板发布到平台共享库；其他会员可以浏览、搜索并下载使用。下载得到的是副本，
改动不会影响发布者，也不会把发布者的数据源带下来。

**Independent Test**：A 发布模板 → B 登录后在共享库检索到并下载 → B 能打开打印；
B 修改并保存 → A 的模板与共享库条目**不变**。

**Acceptance Scenarios**：

1. **Given** A 已登录且有一个云端模板，**When** A 将其提交到共享库，
   **Then** 状态为「待审核」，**尚未**对其他会员可见
2. **Given** 运营审核通过 A 的提交，**When** B 刷新共享库，
   **Then** 能检索到该模板（分类、关键词、尺寸）
3. **Given** B 已登录，**When** B 下载共享模板，**Then** 得到本地副本并可正常打开打印
4. **Given** B 修改了下载的副本，**When** 保存，**Then** **不回写**共享库与原模板
5. **Given** A 取消发布或删除原模板，**When** B 已下载过，
   **Then** B 的本地副本仍可用，但共享库不再展示
6. **Given** 未登录用户，**When** 打开共享模板库，**Then** 先要求登录
7. **Given** 平台下架了某个共享模板，**When** 会员刷新列表，**Then** 不再可见

### User Story 5 - 在桌面端浏览并购买商城商品 (Priority: P2 · US32)

会员在桌面端点「商城」，直接进入 maxLabelMall 的门面站，浏览标签纸等实物商品或其他软件商品，
加购物车、结算、在线支付 —— 与在浏览器里购物完全一致，且**已经是登录状态**。

**Independent Test**：桌面端进入商城 → 顶栏显示已登录 → 加购一件实物商品 → 结算支付成功 →
商城订单列表能看到该订单。

**Acceptance Scenarios**：

1. **Given** 已登录，**When** 打开桌面端商城入口，**Then** 进入 maxLabelMall 并保持登录态
2. **Given** 未登录，**When** 打开商城入口，**Then** 先完成登录再进入
3. **Given** 商品页，**When** 下单支付，**Then** 价格/库存/优惠以服务端为准，桌面端不自行计算
4. **Given** 已在桌面端完成购买，**When** 在浏览器登录同一账号，**Then** 订单、地址、优惠券一致

### User Story 6 - 后台查看每个会员的订阅周期 (Priority: P1 · US33)

运营在后台会员列表/详情中，能看到每个会员的订阅状态与起止时间、剩余天数与来源订单，
用于客服答复"我的会员到什么时候"。

**Independent Test**：给某会员开通订阅后，后台会员详情「订阅」页签展示起止日期与状态；
续费一次后，展示顺延后的新到期日。

**Acceptance Scenarios**：

1. **Given** 会员无订阅，**When** 打开后台会员详情，**Then** 「订阅」页签显示「未订阅」
2. **Given** 会员有有效订阅，**When** 打开详情，**Then** 显示开始日、到期日、剩余天数、来源订单号
3. **Given** 会员订阅已过期，**When** 打开详情，**Then** 显示「已过期」及最后到期日
4. **Given** 会员列表，**When** 查看列表，**Then** 至少有订阅状态与到期时间列

### User Story 7 - 后台查看会员上传的模板与打印记录 (Priority: P2 · US34)

运营在会员详情中查看该会员上传过哪些模板、是否有公开到共享库，并能预览/下载；
还能看到该会员的打印记录（时间、模板、打印机、数量、状态），用于支持与追溯。

**Independent Test**：会员上传 2 个模板并完成 3 次打印 → 后台会员详情两个页签分别显示 2 条与 3 条记录，
且与桌面端本地日志一致；换另一个会员，**看不到**这些数据。

**Acceptance Scenarios**：

1. **Given** 会员上传过模板，**When** 打开「标签模板」页签，**Then** 列出名称、大小、上传时间、是否共享
2. **Given** 会员在桌面端打印成功，**When** 打开「打印记录」页签，**Then** 出现对应记录（按时间倒序）
3. **Given** 一台设备在断网时打印，**When** 联网后，**Then** 后台**不会**自动出现该条记录
   （本期不补传），但桌面端本地日志**仍有**完整记录
4. **Given** 会员提交了一个待审核模板，**When** 运营在后台通过审核，
   **Then** 桌面端共享库出现该模板；**When** 运营驳回并填原因，**Then** 共享库不出现且会员可见驳回原因
5. **Given** 运营查看共享库，**When** 下架某个已公开模板，**Then** 桌面端共享库不再展示
6. **Given** 普通后台账号无相应权限，**When** 访问这些页签/操作，**Then** 被拒绝

### Edge Cases

- **登录态在上传/打印过程中失效**：上传必须失败并保留本地文件；打印必须照常完成（打印不依赖登录）。
- **同一账号两台设备同时上传同名模板**：后上传者不得静默覆盖先上传者，必须给出覆盖/另存选择。
- **订阅到期日当天**：以商城服务端时区为准，全天仍视为有效，到期日次日 00:00 起为过期。
- **重复支付/并发支付同一笔续费订单**：订阅只顺延**一次**，不得因回调重试重复累加。
- **已开通订阅的订单退款**：后台必须能识别该订阅来源于已退款订单并提示运营处理；
  本期不做自动回收（见 Assumptions）。
- **会员被禁用或注销**：桌面端登录态失效；其云端模板与打印记录按后台可见性保留，不级联删除。
- **删除云端模板时它仍在共享库**：其共享条目 MUST 一并下架，不留下无法追溯来源的公开模板。
- **共享模板下架后已下载的副本**：副本仍是用户本地文件，不远程删除。
- **打印记录量很大**：后台分页，单会员默认按时间倒序；不得因数据量大阻塞会员详情页。
- **断网**：本地编辑/打印不受影响；云端与商城入口给出明确提示，不破坏本地数据。

## Requirements *(mandatory)*

### Functional Requirements

#### A. 账户与登录（桌面端）

- **FR-216**: 桌面端 MUST 支持使用商城会员账号登录，复用商城现有登录方式（手机号+验证码、
  手机号+密码、微信扫码）；MUST NOT 自建第二套账号体系。升级后 MUST **移除旧云账户
  （邮箱+密码）登录入口**，只保留商城会员这一套身份（Q52）。
- **FR-217**: 登录鉴权 MUST 由商城完成；桌面端 MUST NOT 保存会员密码，MUST 仅保存会话令牌。
- **FR-218**: 桌面端 MUST 持久化登录态并在重启后自动恢复，MUST 提供显式注销；
  令牌 MUST 加密存储，MUST NOT 明文落盘（沿用 E6 的加密存储做法）。
- **FR-219**: 未登录时桌面端 MUST 保持现有全部本地编辑与打印能力；只有云端模板、共享库与商城
  能力要求登录（保持 E12 的现状，不得收窄）。登录后，云端的**写入**能力（上传、覆盖、发布到共享库）
  MUST 要求订阅当前有效；云端的**读取**能力（浏览、下载自己的模板与共享模板）MUST 只要求登录（Q54）。
  **删除自己的模板、取消共享**属于数据处置权，MUST 不受订阅状态限制。
- **FR-220**: 登录后桌面端 MUST 展示脱敏账号标识与订阅状态（有效 / 已过期 / 未订阅，含到期日）。
- **FR-221**: 桌面端与商城 MUST 互认同一登录态：从桌面端进入商城或共享库 MUST NOT 要求二次登录。
- **FR-222**: 会话失效时桌面端 MUST 引导重新登录，且 MUST NOT 丢失未保存的本地文档。

#### B. 会员订阅与授权

- **FR-223**: 商城 MUST 以「虚拟商品」形态提供 **单一 MaxLabel 会员产品**，并支持按周期购买
  （至少 1 个月与 1 年两种周期，具体以上架商品配置为准）；购买 MUST 走商城既有购物车 → 结算 → 支付流程，
  纯虚拟商品单 MUST 不要求收货地址（复用 E3、Q51）。会员计划映射 MUST 只接受
  **配送方式仅含虚拟商品** 的 SPU，且同一租户同一时刻 MUST 只有一条启用的会员 SPU 映射
  （同一 SPU 下可有多个周期 SKU）。
- **FR-224**: 支付成功后系统 MUST **自动**为该会员生成或顺延订阅，MUST NOT 依赖运营手工开通
  或用户输入激活码；续费 MUST 从原到期日继续累加，MUST NOT 清零或覆盖剩余周期。
  订阅 MUST 绑定会员账号而非设备，同一账号 MAY 在多台设备登录，MUST NOT 要求换机解绑（Q48）。
- **FR-225**: 订阅 MUST 记录所购周期（如 1 个月 / 1 年）、开始时间、到期时间与状态（生效 / 已过期），
  同一会员同一产品同一时刻 MUST 只有一条当前有效订阅。
  **到期时间 MUST 表示最后有效自然日的次日 00:00:00（不含当日）**：到期日当天全天有效，
  次日 00:00 起为过期。
- **FR-226**: 订阅到期后桌面端 MUST 显示「已过期」并提供续费入口；系统 MUST NOT 删除
  会员已上传的云端模板与历史打印记录，MUST 仍允许其浏览与下载自己的模板及共享模板；
  写入限制按 FR-219 执行（上传、覆盖、发布被拒，删除/取消共享不受限）。
- **FR-227**: 桌面端 MUST 提供「购买/续费」入口跳转商城完成购买；MUST NOT 在桌面端内嵌收银台，
  MUST NOT 在桌面端计算价格、优惠或到期日。
- **FR-228**: 订阅状态 MUST 以已支付订单为依据；**订单或会员订单项全额退款后**，后台 MUST 能识别
  该订阅的来源已退款并提示运营处理（本期不做自动回收，见 Assumptions）。
- **FR-229**: 既有授权码 MUST 继续有效，本特性 MUST NOT 废除、重置或强制迁移用户已激活的授权码。

#### C. 云端模板与共享模板

- **FR-230**: 已登录会员 MUST 能把本地模板（桌面端既有模板格式，E8）上传到云端，上传后
  模板的名称、尺寸、对象与本地一致且可正常打开打印。
- **FR-231**: 上传前 MUST 剥离数据库连接密码等敏感字段（沿用 E8 的既有机密剥离做法）。
- **FR-232**: 会员 MUST 能查看、下载、覆盖与删除自己的云端模板；云端模板 MUST 仅对所属会员可见，
  其他会员与未登录用户 MUST NOT 能读取。
- **FR-233**: 会员 MUST 能将自上传的模板**提交**到「平台共享模板库」并取消发布；
  提交后状态为「待审核」，**经运营审核通过后才公开**（Q50）；驳回 MUST 向会员说明原因。
  发布、审核与下架动作 MUST 在后台可追溯（操作人、时间）。
- **FR-234**: 平台共享模板库 MUST 对已登录会员开放浏览与检索（至少支持按分类、关键词、尺寸筛选），
  并支持下载到本地使用。
- **FR-235**: 下载共享模板 MUST 生成本地副本；对副本的修改 MUST NOT 回写共享库或影响原上传者。
- **FR-236**: 共享模板 MUST NOT 携带原上传者的数据库连接、密码或私有业务数据；
  下载者 MUST NOT 能通过共享模板访问原上传者的任何数据源。
- **FR-237**: 云端模板 MUST 有容量上限（沿用现有 1000 个 / 256 MB 量级或服务端可配置的等价上限），
  超限 MUST 给出明确提示且不丢失本地文件。
- **FR-238**: 后台 MUST 提供共享模板的**审核与下架**：对待审核条目可通过或驳回（驳回必填原因），
  对已公开条目可下架；下架后共享库 MUST 不再向会员展示（Q50）。

#### D. 桌面端商城

- **FR-239**: 桌面端 MUST 提供商城入口，可浏览商品分类、列表与详情，并可完成在线购买。
- **FR-240**: 桌面端内的购买 MUST 复用商城既有结算与支付；商品价格、库存、优惠、订单状态
  MUST 由服务端裁决，桌面端 MUST NOT 自行计算或缓存会过期的业务数据。
- **FR-241**: 从桌面端打开商城 MUST 携带当前登录态；未登录时 MUST 先完成登录再进入。
- **FR-242**: 订单、售后等交易管理 MUST 在商城侧完成，桌面端 MUST NOT 复制一套交易管理界面。

#### E. 管理端会员中心

- **FR-243**: 后台会员详情 MUST 新增「订阅」页签，展示每一段订阅的开始、到期、状态、剩余天数
  与来源订单号；会员列表 MUST 至少展示订阅状态与到期时间。
- **FR-244**: 后台会员详情 MUST 新增「标签模板」页签，列出该会员上传的模板（名称、大小、
  上传时间、是否已共享），并支持预览或下载。
- **FR-245**: 后台会员详情 MUST 新增「打印记录」页签，按时间倒序展示该会员上报的打印记录
  （时间、模板名、打印方式、数量/副本、状态、打印机），并支持按时间范围筛选与分页。
  打印记录 MUST 永久保留，本期 MUST NOT 自动清理（Q53）。
- **FR-246**: 上述页签与操作 MUST 沿用后台既有权限体系；下架共享模板等关键操作 MUST 记录
  操作人与操作时间。

#### F. 打印记录上报

- **FR-247**: 桌面端 MUST 在**已登录时自动**把打印记录上报到商城，供后台按会员查看；
  上报字段 MUST 限于结构化字段（时间、模板名、打印方式、数量、副本、状态、打印机）。
  桌面端设置中 MUST 提供开关且**默认开启**；用户关闭后 MUST 停止上报（Q49）。
  打印上报 MUST NOT 因订阅过期而停止（Q54）。
- **FR-248**: 上报 MUST NOT 包含模板数据快照（`dataSnapshot`）、数据库连接信息或标签中的
  客户业务数据；MUST NOT 提供"上报更多字段"的隐藏开关（Q49）。
- **FR-249**: 上报失败 MUST NOT 影响打印本身；本地打印日志 MUST 始终完整保留（保持 E9 的本地能力）。
  本期 MUST NOT 承诺自动补传：未登录或断网期间的记录只留在本地，恢复后不自动回补（Q49）。

#### G. 跨端与安全

- **FR-250**: 桌面端与商城之间的通信 MUST 使用 HTTPS（本机回环地址除外），登录令牌 MUST 加密存储。
- **FR-251**: 服务端 MUST 校验每次云端模板与打印记录请求的归属，MUST NOT 允许跨会员读写。
- **FR-252**: 上传与上报载荷 MUST 做类型、大小与字段白名单校验；非法或超限载荷 MUST 被拒绝
  并返回可理解的提示。

### Key Entities

**术语约定**：正文统一用「会员授权」（业务/文案）与「会员订阅」（数据/后台实体）指同一概念；
「云端标签模板 / 私有模板」指会员自己的模板；「平台共享模板」指审核通过后的公开副本。
代码命名以契约中的 `subscription` / `cloud-template` / `shared-template` 为准。

- **会员账号**：复用商城 `member_user`（手机号、昵称、企业名称、等级、状态），是两端唯一身份。
- **会员订阅**：一条记录 = 某会员 × MaxLabel 会员产品 × 一个周期；含周期规格（如 1 个月 / 1 年）、
  开始时间、到期时间、状态、来源订单号；有效订阅同时是**云端写入能力的闸门**（Q54）。
  **当前商城无此实体**（E2），需新增。
- **云端标签模板**：归属会员、模板名称、模板内容（`.msdx` JSON）、大小、上传时间、
  是否已发布到共享库、共享状态（待审核/已公开/已下架）。
- **平台共享模板条目**：云端模板的公开视图，含分类、关键词、尺寸、发布者昵称与审核状态。
- **打印记录**：会员、设备标识、打印时间、模板名、打印方式、数量/副本、状态、打印机；
  **不含**业务数据快照（Q49）。
- **商城商品与订单**：复用 `product_spu` / `trade_order`，会员授权商品为虚拟商品（E3）。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-076**: 新客户从桌面端发起登录到看到自己的订阅状态 ≤ 2 分钟（含首次短信验证/资料补全）。
- **SC-077**: 支付成功后，桌面端在**一次刷新或重开**内显示有效订阅与正确到期日，无需人工激活。
- **SC-078**: 连续续费 3 次后，到期日精确等于「初始到期日 + 3 个周期」，误差 0 天。
- **SC-079**: 登录后上传 100 个模板（合计 ≤ 100 MB）成功率 ≥ 99%，单个失败不影响其余上传。
- **SC-080**: 平台发布/审核通过的共享模板，其他会员在刷新后 ≤ 1 分钟内可见；下架后同样 ≤ 1 分钟内不可见。
- **SC-081**: 运营从会员列表进入任一会员的订阅 / 模板 / 打印记录页签均 ≤ 3 次点击。
- **SC-082**: 在**开启上报且全程在线**的前提下，同一会员、同一时间范围内，后台打印记录条数
  与桌面端本地日志条数一致（误差 0）。
- **SC-083**: 未登录或断网时，桌面端本地编辑与打印成功率 100%，与升级前一致（回归）。
- **SC-084**: 跨会员越权读取他人模板或打印记录的尝试成功率 0%（负向测试）。
- **SC-085**: 客户完成一次会员授权购买（选商品 → 结算 → 支付 → 订阅生效）≤ 3 分钟。
- **SC-086**: 既有授权码用户在升级后，本地可用性与授权展示不变（回归 100%）。
- **SC-087**: 订阅过期的会员仍能浏览与下载自己已上传的模板（成功率 100%），
  但上传 / 覆盖 / 发布的请求 100% 被拒绝（负向测试）。

## 范围边界（非目标）

- **不做**桌面端内的支付收银台、订单中心、售后中心（跳商城）。
- **不做**设备绑定与多设备授权管理/解绑后台（Q48 已定不绑设备）。
- **不做**模板版本历史、协同编辑、评论/评分（本期只要上传、共享、下载）。
- **不做**打印记录的实时看板/统计报表（本期只要按会员可查）。
- **不做**旧云账号/旧云端模板的迁移与双轨并行；更新后桌面端只使用商城会员体系（Q52）。
  既有授权码不受影响（FR-229）。
- **不改**打印流水线、模板格式与打印协议（宪法硬约束）。

## Assumptions

- 会员账号直接复用商城现有 `member_user`；桌面端不自建账号，也不再要求邮箱+密码注册；
  旧云账户在升级后停用、不迁移、不与商城账号并行（Q52）。
- 登录方式复用商城现有三种；桌面端的具体登录承载方式（内嵌窗口 / 系统浏览器回跳）由**计划阶段**决定。
- 会员授权为**单一产品、周期可选**（至少月/年），本期不做多档会员（Q51）。
- 订阅**按会员账号**计，不按设备绑定；同一账号可在多台设备登录（Q48）。
- 订阅**不改变**桌面端**本地**功能可用性（沿用 E7 "功能不分版本"）；但它对**云端写入**设闸：
  过期后云端只读，本地编辑、打印与打印上报不受影响（Q48、Q54）。
- 打印记录**登录后自动上报**，只含结构化字段、不含数据快照；用户可在设置中关闭，默认开启（Q49）。
- 打印记录上报失败或未登录时**本期不做自动补传**，只在本地保留（Q49）。
- 已上报的打印记录**永久保留**，不做自动清理（Q53）。
- 共享模板采用**先审后发**：会员发布为"待审核"，运营审核通过后才公开；驳回需填原因（Q50）。
- 订阅订单退款后**不做自动回收或扣减周期**，后台只保证"来源订单已退款"可见，由运营人工处理；
  自动回收属后续决策。
- 云端模板容量沿用现有 1000 个 / 256 MB 量级，作为服务端可配置上限。
- 既有授权码继续有效，不强制迁移；旧云服务账号是否迁移不在本期范围。
- 桌面端启动页的旧商城链接（`www.360code.com`）将被替换为 maxLabelMall 入口；旧链接是否保留由计划阶段确认。
- 管理端在 yudao 既有会员详情页扩展，不新建独立后台；权限沿用 yudao 权限体系。
- 沿用既有虚拟商品交付流程；订阅开通在**支付成功时自动完成**，不依赖"运营点无需发货"这一步（Q48）。

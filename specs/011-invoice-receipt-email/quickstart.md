# 手工验证清单（011 发票收据 / 邮箱 / 抬头顺序）

**前置**：已执行 `020-invoice-receipt-email.sql`，并**按 SQL → 后端 → 两个前端**的顺序发版。

## 一、C 端结算页

1. 勾选「需要开发票」→ 先选「企业 / 个人」→ 再选票种；**抬头选择器应在此之后出现**。
2. 选「收据」→ 只填抬头名称 → 能提交（不要求税号）。
3. 选「个人」+「收据」→ 通过；选「个人」+「专票」→ 仍被拒。
4. 抬头选择器只列**同企业/个人、同票种**的抬头；换票种/类型后列表随之变化。
5. 邮箱留空 → 通过；填 `abc` → 提示「邮箱格式不正确」；填合法邮箱 → 通过。
6. 下单成功 → 订单详情开票信息显示票种「收据」与邮箱。

## 二、C 端补开 / 抬头簿

1. 订单详情「申请开票」重复上面顺序。
2. 抬头簿出现**普票 / 专票 / 收据**三段；收据段可新增，新增弹层预选收据。
3. 抬头里填邮箱并保存 → 结算页选中该抬头时邮箱自动带出。

## 三、后台

1. 开票列表：票种列能显示「收据」；新增「邮箱」列。
2. 「开具发票」弹层：显示「票据类型」「邮箱」；上传 PDF/图片后可开具。
3. 收据的状态、作废、退款撤回与发票一致。

## 四、回归（006）

- 企业普票/专票仍要求税号；个人 + 专票仍拒；抬头快照/一单一条/退款撤回不变。
- 006 的后端与前端既有用例全绿。

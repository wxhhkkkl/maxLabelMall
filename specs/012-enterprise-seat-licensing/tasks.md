## Dependencies & Execution Order

### Phase Dependencies

- **Phase 1 Setup**：无依赖，立即开始
- **Phase 2 Foundational**：依赖 Setup；**阻塞所有用户故事**
- **Phase 3 ~ 9**：依赖 Foundational；同一优先级内可并行，按 P1 → P2 → P3 顺序交付
- **Phase 10 Polish**：依赖所有目标故事完成

### User Story Dependencies

| 故事 | 依赖 | 可独立验证 |
|---|---|---|
| US40 购买 | Foundational | 种子企业 + 企业计划 → 购买 → 批次 |
| US41 分配席位 | Foundational（T020 席位服务）；**前端依赖 US40**（T033 `GET /member/org/get` + T036 企业中心壳） | 种子批次 → 分配/撤销 |
| US42 成员看到权益 | Foundational（T021 解析器） | 种子批次 + 席位 → 桌面端显示/上传 |
| US43 成员管理 | Foundational（T018）；前端成员面板依赖 US41 | 种子企业 + 会员 → 加入/移出/转交 |
| US44 运营兜底 | Foundational（T017~T020） | 运营建企业 → 代操作 |
| US45 续费与到期 | Foundational（T019/T020）；前端批次面板依赖 US40 | 直接改批次时间 → 续费/过期 |
| US46 隐私 | US41 / US43（接口存在后做负向测试） | 席位上成员 → 企业管理员无模板/打印权限 |

### Within Each Story

- 测试（T0xx）先写并确认失败 → 服务/控制器 → UI → 集成
- 前端 API 客户端先于视图；视图测试先于视图实现
- 每完成一个故事，按 quickstart 对应小节验证，再进入下一个优先级

### Parallel Opportunities

- Setup：T002~T007 可并行（不同文件）
- Foundational：T008~T016 测试可并行；实现按 T017~T026 依赖顺序推进
- US40：T027~T032 测试可并行；T035/T036/T037 前端可与 T033/T034 后端并行
- 任何两个故事之间（除 US46 依赖 US41/US43 外）可由不同人并行开发
- 所有 `[P]` 任务在不同文件上，可并行

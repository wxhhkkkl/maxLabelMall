## 1. 计价口径（先做，最容易错）

用「可移除铜版」做对照：

| 参数 | 值 |
|---|---|
| 基价 | 1138 分/㎡（11.38 元/㎡） |
| 材质打印系数 | 4 |
| 印刷系数 | 1.5 |
| 区间 0-10 ㎡ | 打印系数 2.0，模切系数 1.0 |
| 打印初始价 | 20000 分 |

| # | 输入 | 预期 |
|---|---|---|
| 1.1 | 50×100mm、1000 张、只打印、不加急 | 单件 0.005 ㎡、总面积 5 ㎡；打印计算价 `1138×4×2.0×5 = 45520` 分；实收 455.20 元 |
| 1.2 | 同上但总面积为 10 ㎡（如 2000 张） | 落到 **10-100 档**（左闭右开），系数换成该档的值 |
| 1.3 | 数量 1 张 | 计算价远小于 200 元，实收 **200 元**（最低收费） |
| 1.4 | 模式 = 标签印刷（多色） | 只收印刷：`max(60000, 1138×1.5×总面积)`；打印为 0 |
| 1.4b | 模式 = 多色印刷+黑色打印 | 两项都收：打印 + `max(60000, 1138×1.5×总面积)` |
| 1.5 | 勾选模切（区间模切系数 0） | 模切计算价为 0，但实收 = 模切初始价（400 元）；**选项仍可选**（Q105=B） |
| 1.6 | 勾选加急 | 加急费 = `max(5000, 小计 × 0.1)`；页面**不得**出现具体交期 |
| 1.7 | 金额含小数 | 一律按分四舍五入；页面与订单金额一致 |

## 2. C 端：定制并支付（SC-140 / SC-145）

| # | 操作 | 预期 |
|---|---|---|
| 2.1 | 打开 `/customization`，选材质、填 50×100、1000 | 不刷新即出现价格明细，耗时记录（人工计时） |
| 2.2 | 改数量 / 尺寸 / 勾选工艺 | 明细随之更新；越界时提示该材质的允许范围 |
| 2.3 | 上传 1 个 PDF | 显示文件名，可删除、可重传 |
| 2.4 | 上传第 6 个文件 / 传 .exe / 传 18MB | 提交前被拦，提示具体原因（单文件上限 16MB） |
| 2.5 | 未登录点「立即下单」 | 引导登录；登录后回到页面，**已填内容不丢失** |
| 2.6 | 选择收货地址并提交 | 生成待支付订单；金额 = 页面展示金额（含运费） |
| 2.7 | 完成支付 | 订单进入「待发货」；**不出现**「生产中」等新状态 |
| 2.8 | 「我的订单」打开该单 | 看到材质、尺寸、数量、工艺、加急、备注、价格明细、文件可下载 |

**SC-140 计时口径**：从进入定制页到提交成功；目标 ≤ 5 分钟（含上传一个文件）。

## 3. 后台：定制单与配置（SC-143）

| # | 操作 | 预期 |
|---|---|---|
| 3.1 | 订单列表筛选「定制」 | 只显示定制单；普通单不出现 |
| 3.2 | 打开定制单详情 | 材质、宽高、面积、数量、印刷/模切/加急、备注、文件下载、价格明细齐全（≤ 2 次点击） |
| 3.3 | 对照 `param_snapshot` | 与下单时参数一致，不是当前参数 |
| 3.4 | 材质页新增 / 编辑 / 停用 | 前台可选项随之变化；停用材质不出现在定制页 |
| 3.5 | 保存断档 / 重叠的区间 | 拒绝保存，并指出冲突位置 |
| 3.6 | 修改一个初始价并保存 | 下一次报价立即使用新值 |

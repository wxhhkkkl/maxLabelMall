## 背景与问题

商城现在只能卖**规格固定**的标准商品；客户要按自己的标签尺寸、材质与工艺印刷，只能线下沟通、人工报价：

| # | 现状 | 证据 |
|---|---|---|
| E1 | 没有任何在线定制入口，标准商品链路无法承载「按尺寸计价」 | storefront 的商品 → 购物车 → 结算都是固定 SKU 与单价 |
| E2 | 定制报价完全依赖人工，客户拿不到即时价格 | 服务端无报价能力；旧系统 `360code` 的印刷服务页（用户提供的参考链接）是唯一的自助报价入口 |
| E3 | 定制要求散落在聊天记录里，生产与客服无法结构化查看 | 订单只有商品、数量、地址、备注，没有材质 / 尺寸 / 工艺字段 |
| E4 | 业务方已经在用一套**参数化计价模型** | 用户提供的三张后台截图：材质 × 面积区间 → 打印 / 模切系数；材质基价 / 打印系数 / 印刷系数；打印、印刷、模切、加急**初始价**与**加急系数** |
| E5 | 商城已有会员、订单、支付、发票、物流、售后与文件上传能力 | 复用既有能力，不重造（宪法原则 III） |

**问题**：把「定制 → 报价 → 下单 → 支付」搬到一个客户可自助完成的页面，并让运营在后台按定制单单独查看完整要求。

## Clarifications

### Session 2026-11-01

- **Q91 金额的精确计算规则？**（2026-11-01 所有者拍板）
  → **C：初始价作为「最低收费」，正常按系数计价。** 口径固定如下：

  | 项 | 计算价 | 实收 |
  |---|---|---|
  | 单件面积 | `S = 宽(mm) × 高(mm) ÷ 1,000,000`，即 ㎡（见 Q102 的单位口径） | — |
  | 整单总面积 | `S × 数量`，用于匹配面积区间（Q103） | — |
  | 打印（模式含打印时） | `材质基价 × 材质打印系数 × 区间打印系数 × 整单总面积`（Q104） | `max(打印初始价, 计算价)` |
  | 印刷（模式含印刷时） | `材质基价 × 印刷系数 × 整单总面积` | `max(印刷初始价, 计算价)` |
  | 模切（选了才有） | `材质基价 × 区间模切系数 × 整单总面积` | `max(模切初始价, 计算价)` |
  | 加急（选了才有） | `小计 × (加急系数 − 1)` | `max(加急初始价, 计算价)` |
  | 合计 | — | `打印实收 + 印刷实收 + 模切实收 + 加急实收` |

  金额以「分」为单位、四舍五入，沿用商城既有金额精度；**加急费只对小计收取一次**，
  不参与自身系数的复利。

- **Q92 设计文件是否必填、允许的格式与大小？**（2026-11-01 所有者拍板）
  → **A：必须上传**。接受 PDF / AI / CDR / JPG / PNG；一张定制单 1~5 个文件。
  单文件上限经 **Q106 修订为 16MB**（与既有上传接口一致）。
  文件不合规时在提交前拦住并说明具体原因（格式 / 大小 / 数量）。

- **Q93 材质与计价参数是否在管理端维护？**（2026-11-01 所有者拍板）
  → **A：本期包含完整配置模块** —— 材质、面积区间、四个初始价与加急系数都可增删改；
  保存后新报价立即生效，历史订单金额不变，并留下操作记录。

- **Q94 面积正好落在两个区间的交界值上，归到哪一档？**（2026-11-01 所有者拍板）
  → **A：左闭右开** —— 面积属于 `[最小面积, 最大面积)`；最大面积为 `0` 时表示
  `[最小面积, +∞)`（对应截图里的「2000-0」）。因此边界值一律归入**上界更高**的那一档，
  且不会出现「面积落在所有区间之外」的空洞；只有小于材质最小起始面积时才会无档可归。

- **Q95 定制订单支付成功后怎么流转？**（2026-11-01 所有者拍板）
  → **A：完全沿用普通订单状态** —— 支付成功即进入既有「待发货」，运营按普通订单发货；
  本期**不新增**「待生产 / 生产中」等生产状态，也不引入独立的履约状态机。

- **Q96 定制订单用户端能不能自助退款？**（2026-11-01 所有者拍板）
  → **B：用户端不提供自助退款**，只保留后台人工退款通道（与 Q79/Q82 的订阅类订单口径一致）。
  已投产的定制品一旦自助退掉会产生实际损失；客服仍可按实际情况在后台人工处理。

- **Q97 定制数量与成品尺寸的取值范围？**（2026-11-01 所有者拍板）
  → **B：由后台按材质维护** —— 每个材质有自己的数量上下限与成品宽高上下限；
  前端校验与后端校验使用同一份材质配置，超限时提示该材质的允许范围。

- **Q98 勾选加急后要不要承诺交期？**（2026-11-01 所有者拍板）
  → **A：不承诺具体交期** —— 加急只做「加价 + 优先排产」，页面文案只表达「优先处理」，
  不出现任何小时/天数；实际交期由客服沟通确认。

- **Q99「短时间内的重复提交」按多长时间判定？**（2026-11-01 所有者拍板）
  → **A：60 秒** —— 同一客户在 60 秒内提交**完全相同配置**（材质、尺寸、数量、工艺、加急、
  文件、备注）时只生成一笔订单；超过 60 秒或配置有变化视为新下单。

- **Q100 同一材质的面积区间是否必须连续？**（2026-11-01 所有者拍板）
  → **A：必须连续覆盖** —— 从最小面积起首尾相接（相邻区间的上界 = 下一区间的下界），
  最后一条上界为 `0`（无上限）；重叠、倒挂或断档一律**拒绝保存**并指出具体位置。

- **Q101 提交时服务端价格与页面展示不一致怎么办？**（2026-11-01 所有者拍板）
  → **A：先确认再建单** —— 服务端返回最新报价与「已变更」标识，**不创建订单**；
  客户确认新价格后再次提交，才生成订单并进入支付。

- **Q102 截图里的计价数值用什么单位？**（2026-11-01 所有者拍板）
  → **材质基价按「元/㎡」，四个初始价按「元」**。对应 Q91 的公式：面积按 ㎡ 计
  （`S = 宽(mm) × 高(mm) ÷ 1,000,000`），基价与初始价以元为单位、落库为分。
  例（可移除铜版：11.38 元/㎡、材质打印系数 4、0-10 ㎡ 区间系数 2.0）：
  1 张 50×100mm 的整单总面积 0.005 ㎡，打印计算价 ≈ 0.46 元，按 200 元打印初始价收取；
  1000 张时整单总面积 5 ㎡，计算价 11.38 × 4 × 2.0 × 5 ≈ 455 元（高于初始价，按计算价收）。

- **Q103 面积区间按单件面积还是整单总面积匹配？**（2026-11-01 所有者拍板）
  → **A：整单总面积（单件面积 × 数量）**。截图里的 0-10 / 10-100 / 100-200 / 200-500 /
  500-2000 / 2000+ 是订单量级；系数随面积增大而降低（2.0 → 1.4），属于批量折扣。

- **Q104 面积区间表的打印系数与材质表的打印系数怎么组合？**（2026-11-01 所有者拍板）
  → **A：相乘** —— 打印计算价 = `材质基价 × 材质打印系数 × 区间打印系数 × 整单总面积`。
  两张表的列全部参与计价；以后想弱化某一层，把它配成 `1` 即可。

- **Q105 面积区间的「模切系数 = 0」是什么意思？**（2026-11-01 所有者拍板）
  → **B：不收按面积的模切费，但仍收模切初始价**。即模切实收 = `max(模切初始价,
  材质基价 × 0 × 整单总面积) = 模切初始价`；**不代表该尺寸不能模切**。

- **Q106 设计文件上限与既有上传限制冲突怎么办？**（2026-11-01 所有者拍板）
  → **A：把上限对齐到 16MB** —— 与 `spring.servlet.multipart.max-file-size` 一致，
  不改全站上传配置；服务端仍校验数量、扩展名与 URL 域名，大小由上传接口自身兜底。

- **Q107 定制订单的开票在哪个环节承接？**（2026-11-01 所有者拍板）
  → **A：与普通订单一致，在提交前选择** —— 定制页提供「是否开票」，复用既有发票抬头，
  并与订单**同一事务**落库（沿用 006 的 Q32 口径）；不选择 = 不开票。

- **Q108 业务模式怎么定？**（2026-11-01 所有者按参考页面拍板）
  → **A：三选一** —— `1 标签印刷（多色）` / `2 标签打印（黑色）` / `3 多色印刷+黑色打印`。
  计价只收所选模式对应的项；**不再是「打印必选 + 印刷可选」**。

- **Q109 定制流程要不要按参考页面做成四步向导？**（2026-11-01 所有者拍板）
  → **A：完整四步向导** —— 加工形式（含「定制空白标签」，共 4 选）→ 材质 → 成品形态（卷筒/平张、整张规格、
  圆角/撕裂线、行列与间距、轴芯内径）→ 数量与提交（定制/实际数量、模板名称、文件、备注、加急）。
  排版与成品形态字段**只随订单保存、作为生产要求**，价格仍按已上线的参数模型计算（Q91~Q108）。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 客户在线定制并支付 (Priority: P1)

客户从商城进入「印刷定制」，选择材质，填写成品尺寸与数量，选择印刷方式、是否需要模切、是否加急，上传设计文件并填写备注；页面实时给出价格明细；提交后生成待支付订单并完成支付。

**Why this priority**：这是本次需求的核心价值 —— 把现在靠电话 / 微信完成的「报价 + 下单」搬到线上；没有它，后续任何后台能力都没有数据来源。

**Independent Test**：在测试环境用一组预置材质与参数，走完「选材质 → 填尺寸数量 → 选工艺 → 看报价 → 传文件 → 提交 → 支付」全流程，订单金额与页面明细一致。

**Acceptance Scenarios**：

1. **Given** 客户在定制页并已选择材质，**When** 填写尺寸与数量，**Then** 页面不刷新即显示价格明细（材料 / 印刷 / 模切 / 加急 / 合计）。
2. **Given** 已显示价格明细，**When** 修改任一影响价格的输入，**Then** 明细与合计随之更新。
3. **Given** 客户未登录，**When** 点击「立即定制」，**Then** 引导登录；登录完成后回到定制页，已选材质与已填内容不丢失。
4. **Given** 配置完整且价格未发生变更，**When** 提交，**Then** 生成一笔待支付订单，订单金额等于提交前展示的最终合计。
5. **Given** 待支付定制订单，**When** 支付成功，**Then** 订单进入既有的「待发货」状态；支付超时则按既有规则自动取消。
6. **Given** 已生成的定制订单，**When** 客户在「我的订单」中打开，**Then** 能看到材质、尺寸、数量、工艺、加急、备注与价格明细。
7. **Given** 客户需要开票，**When** 在提交前选择发票抬头并提交，**Then** 开票记录与订单同一事务生成；不选择则不开票。

### User Story 2 - 运营在后台查看定制订单的完整要求 (Priority: P1)

运营在管理端订单列表里能一眼分清哪些是定制订单，筛出定制单后，打开详情即可看到生产所需的全部要求与设计文件。

**Why this priority**：用户明确要求「后台可以单独查看到定制订单的要求」；没有这个能力，前端收到的定制单无法进入生产。

**Independent Test**：用一笔测试定制订单，运营在订单列表按「定制」筛选并打开详情，核对全部要求与价格明细；同时确认普通订单详情不受影响。

**Acceptance Scenarios**：

1. **Given** 混合了定制单与普通单的订单列表，**When** 使用「定制」筛选，**Then** 只显示定制订单。
2. **Given** 一笔定制订单，**When** 打开详情，**Then** 展示材质、成品尺寸、面积、数量、印刷方式、模切、加急、备注与设计文件（可下载）。
3. **Given** 一笔定制订单，**When** 查看价格，**Then** 能看到价格明细与**下单时的参数快照**（而不是当前参数）。
4. **Given** 任一普通订单，**When** 打开详情，**Then** 展示与改造前一致。

### User Story 3 - 运营维护材质与计价参数 (Priority: P2)

运营在后台维护可售材质、材质的面积区间系数、四个初始价与加急系数；保存后新报价立即生效，历史订单金额不变。

**Why this priority**：纸张与工艺成本会变；如果参数写死，每次调价都要改代码发版。但首期可以先按给定参数初始化，因此排在 P2。

**Independent Test**：新增一个材质与一条面积区间、修改一个初始价，前台报价随新参数变化；改动前已生成的订单金额保持不变。

**Acceptance Scenarios**：

1. **Given** 管理端材质列表，**When** 新增 / 编辑 / 停用一个材质（含数量与宽高上下限），**Then** 前台可选项与允许范围随之变化，停用材质不出现在定制页。
2. **Given** 一个材质，**When** 维护多条面积区间（最小面积、最大面积、打印系数、模切系数），**Then** 区间必须从最小面积起首尾相接、最后一条上界为 0；重叠、倒挂或断档时拒绝保存并指出位置。
3. **Given** 四个初始价与加急系数，**When** 修改并保存，**Then** 下一次报价立即使用新值。
4. **Given** 参数已变更，**When** 查看变更前生成的订单，**Then** 金额与参数快照保持不变。
5. **Given** 任一参数变更，**When** 查看操作记录，**Then** 能看到操作人、时间与变更前后值。

### Edge Cases

- **Q110 四步向导的页面形态？**（2026-11-01 所有者拍板）
  → **单页渐进，不做上一步/下一步** —— 选完第一步后，第二步/第三步/第四步依次在同一页出现；
  标签宽高放在第三步；第三步只有「平张」才显示每张行数；列数选定后展示**预估纸宽**；
  行间距/列间距固定 3mm、不提供输入。边角为「圆角 / 直角」，撕裂线是独立开关。

- **Q111 实际数量与 LabelShop 模板名称还要吗？**（2026-11-01 所有者拍板）
  → **A：去掉** —— 页面不再采集这两个字段；数据库列保留（可空/有默认），后续可随下次迁移清理。

- **面积小于材质的最小起始面积**：没有任何区间可以匹配时不能下单，必须提示该材质的可选面积范围（上界开放，不存在「面积过大」的空档）。
- **区间配置重叠 / 倒挂 / 断档**：后台保存时必须拒绝，并指出冲突或断档的具体位置（Q100=A）。
- **数量 / 尺寸超出材质允许范围**：0、负数、小数、低于下限或高于上限时阻止提交，并按该材质的配置提示允许范围。
- **文件不合规**：格式不支持、超过大小上限、上传中断 —— 必须明确提示，并允许重新选择（Q92 决定上限）。
- **客户停留期间参数被改价**：提交时服务端按最新参数重算；若与页面展示不一致，**不创建订单**，页面展示新价格与差额，客户确认后再次提交才生成订单（Q101=A）。
- **重复提交**：连点或网络重试不得生成多笔订单。
- **支付超时 / 客户取消**：与普通订单一致，不产生生产任务。
- **用户要求退款**：用户端不出现自助退款入口；须引导联系客服，由运营在后台人工处理（Q96=B）。
- **无可售材质**：页面显示空状态并说明原因，不出现可以进入死路的入口。
- **定制单与普通商品同车**：定制单独立下单，不与其他商品合并（见 FR-379）。

## Requirements *(mandatory)*

### Functional Requirements

**定制入口与配置**

- **FR-356**: 商城 MUST 提供「印刷定制」入口，客户可从主导航或定制落地页进入。
- **FR-357**: 定制页 MUST 只展示后台当前**可售**的材质；停用材质 MUST NOT 出现。
- **FR-358**: 客户 MUST 能选择一种材质，并填写成品宽度与高度（单位 mm）；宽高 MUST 落在该材质配置的上下限内（Q97=B）。
- **FR-359**: 系统 MUST 由宽高换算面积，并按「整单总面积（单件面积 × 数量）、左闭右开」匹配该材质的面积区间（`总面积 ∈ [最小, 最大)`；最大值为 `0` 表示 `[最小, +∞)`），据此确定本次的区间打印系数与模切系数（Q94=A / Q103=A）。
- **FR-360**: 客户 MUST 能输入定制数量（正整数）；系统 MUST 按该材质配置的数量上下限校验并给出具体原因（Q97=B）。
- **FR-361**: 客户 MUST 在四种加工形式中单选：**标签印刷（多色）/ 标签打印（黑色）/ 多色印刷+黑色打印 / 定制空白标签**；计价只收所选模式对应的项（Q108）。
- **FR-362**: 客户 MUST 能选择是否需要模切；模切价格 MUST 使用所选面积区间对应的模切系数，系数为 `0` 时表示不收按面积的模切费、但仍按模切初始价收取（Q105=B）。
- **FR-363**: 客户 MUST 能勾选加急；勾选后 MUST 按加急系数计价，并在订单要求中保留「加急」标记；页面 MUST NOT 承诺具体交期，文案只表达「优先处理」（Q98=A）。
- **FR-367**: 客户 MUST 至少上传 1 个设计文件，最多 5 个；仅接受 PDF / AI / CDR / JPG / PNG，单文件 MUST NOT 超过 **16MB**；不合规 MUST 在提交前拦截并说明原因（Q92=A / Q106=A）。
- **FR-368**: 客户 MUST 能填写备注（选填）；页面 MUST 展示字数上限。

**计价**

- **FR-364**: 定制页 MUST 展示价格明细（材料、印刷、模切、加急、合计），任一影响价格的输入变化后 MUST 更新。
- **FR-365**: 金额 MUST 由服务端按**当前生效参数**计算并以服务端结果为准；前端展示 MUST NOT 作为支付依据。
- **FR-366**: 金额 MUST 按 Q91=C 的口径计算：打印按「材质基价（元/㎡）× 材质打印系数 × 区间打印系数 × 整单总面积（㎡）」，印刷/模切按各自系数 × 整单总面积，再以对应初始价（元）作为**最低收费**取两者较大值；加急费按小计的「加急系数 − 1」计算并以加急初始价托底；金额以分为单位四舍五入（Q102 / Q103 / Q104）。

**下单与支付**

- **FR-369**: 提交定制 MUST 要求登录；未登录时 MUST 引导登录，登录后 MUST 保留已填内容。
- **FR-370**: 提交 MUST 生成一笔待支付订单，订单金额 MUST 等于服务端最终报价；若最终报价与提交时页面展示的不一致，MUST NOT 创建订单，而是返回最新报价并要求客户确认后重新提交（Q101=A）。
- **FR-371**: 订单 MUST 固化下单时的**参数快照**与定制要求；后续参数变更 MUST NOT 改变已生成订单。
- **FR-372**: 定制订单 MUST 走既有支付流程，支付结果 MUST 以服务端支付回执为准；支付成功后 MUST 进入既有的「待发货」状态，本期不新增生产状态（Q95=A）。
- **FR-373**: 定制订单 MUST 支持既有的收货地址、运费、发票、物流与售后能力；发票 MUST 在提交前选择、复用既有抬头并与订单同一事务落库（Q107=A）；用户端 MUST NOT 提供自助退款入口，退款 MUST 仅由后台人工发起（Q96=B）。
- **FR-374**: 客户 MUST 能在「我的订单」中查看定制订单的完整要求与价格明细。
- **FR-378**: 同一客户在 60 秒内提交**完全相同配置**（材质、尺寸、数量、工艺、加急、文件、备注）时 MUST NOT 生成多笔订单；超过 60 秒或配置有变化视为新下单（Q99=A）。
- **FR-379**: 定制订单 MUST NOT 与普通商品合并到同一笔订单。

**后台**

- **FR-375**: 管理端订单列表 MUST 能识别定制订单，并支持「只看定制订单」的筛选。
- **FR-376**: 管理端定制订单详情 MUST 展示材质、成品尺寸、面积、数量、印刷方式、模切、加急、备注、设计文件（可下载）与价格明细。
- **FR-377**: 管理端 MUST 提供材质（含数量上下限与成品宽高上下限）、面积区间、四个初始价与加急系数的维护能力（新增 / 编辑 / 停用），保存后新报价立即生效（Q93=A / Q97=B）；面积区间 MUST 连续覆盖（重叠、倒挂、断档一律拒绝保存并指出位置，Q100=A）。
- **FR-380**: 参数变更 MUST 留下操作记录（操作人、时间、变更前后值）。
- **FR-381**: 定制流程 MUST 分四步：加工形式 → 材质（含说明）→ 成品形态 → 数量与提交；当前步骤未完成 MUST NOT 进入下一步（Q109）。
- **FR-382**: 成品形态 MUST 支持卷筒（卷轴）与平张（单张）；平张 MUST 记录整张规格（A4/其他），卷筒 MUST 记录轴芯内径（25.4 / 76.2 / 40mm）。
- **FR-383**: 边角 MUST 为「圆角 / 直角」二选一，撕裂线为独立开关；排版 MUST 记录每张行数（仅平张）、列数，行距/列距固定 3mm；列数变化后 MUST 展示预估纸宽（列数 ×（标签宽 + 3mm））。
- **FR-384**: 数量步骤 MUST 只记录定制数量；设计文件与备注在该步骤提交。（Q111：不再采集「实际数量」与「LabelShop 模板名称」）

### Key Entities *(include if feature involves data)*

- **定制材质**：可售的印刷材料；含名称、基价、打印系数、印刷系数、数量上下限、成品宽高上下限、启停状态、排序。
- **面积区间规则**：隶属于某个材质；含最小面积、最大面积（允许开放式上界）、打印系数、模切系数。
- **计价参数**：全局的打印初始价、印刷初始价、模切初始价、加急初始价与加急系数。
- **定制订单**：与一笔订单一一对应；含材质、成品宽高、面积、数量、印刷方式、模切、加急、备注、设计文件、价格明细与**下单时的参数快照**。
- **设计文件**：客户上传的印刷源文件；含文件名、大小、类型、上传人、上传时间；归属某一笔定制订单。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-140**: 首次使用的客户在 5 分钟内完成一次定制下单（含上传）；常规配置下页面内跳转不超过 3 次。
- **SC-141**: 抽检 20 笔定制订单，用后台参数重算的金额与订单金额一致率 100%。
- **SC-142**: 调价后，调价前已生成的定制订单金额变化数为 0。
- **SC-143**: 运营从订单列表到看到完整定制要求，点击次数不超过 2 次。
- **SC-144**: 定制订单的支付成功率不低于同期普通商品订单（以 95% 为达标线）。
- **SC-145**: 在常见网络条件下，95% 的定制页报价在输入变化后 1 秒内更新。

## 范围边界（非目标）

- **不做在线设计/排版工具**：客户自行准备源文件，商城只收集要求与文件。
- **不做生产进度状态机**：定制单沿用既有订单状态（Q95=A），不新增「待生产 / 生产中」。
- **不做自动拼版与拼版报价**：一张版面里排多个标签的计价不在本期。
- **不接生产系统**：不与 MES / ERP / 印刷机对接，定制要求以订单数据与文件为准。
- **本期只做 Web 门面站（storefront）**：小程序与桌面端不做定制入口。
- **不做人工报价兜底流程**：金额由参数按 Q91 的口径直接计算，客户即看即付。

## Assumptions

- 客户已登录或愿意登录后才能下单；登录、收货地址、支付、发票、物流、售后**全部复用**既有能力。
- 定制订单是**独立订单**：不进购物车、不与其他商品混单、不占库存（按需生产）。
- 计价参数沿用用户提供的旧系统模型（材质基价 + 面积区间系数 + 三个初始价 + 加急系数）。
- 面积单位按 **㎡** 参与计价（Q102），面积区间按**整单总面积**（㎡）配置（Q103）；Q91 的公式已按 `S = 宽(mm) × 高(mm) ÷ 1,000,000` 固化。
- 设计文件复用现有文件存储能力；上传即视为客户已授权将其用于本次生产。
- 定制订单默认**不参与**优惠券、会员折扣等既有促销；若需要叠加，需另行明确。
- 当前商城的业务租户为「御旺宸发」（tenant 162），定制材质与参数按该租户配置。
- 定制印刷品的售后沿用既有规则；用户端不提供自助退款（Q96=B），所有退款由运营在后台人工处理。

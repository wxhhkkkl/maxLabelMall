# 功能规格：共享内容空间（个人 / 企业 / 平台）

> 编号续 015：本规格从 **FR-391 / SC-149 / US50 / Q115** 接着往下排
> （015 排到 FR-390 / SC-148 / US49 / Q114）。

**Feature Branch**: `016-shared-content-space`
**Created**: 2026-11-05
**Status**: Draft
**Input**: User description: "共享模板做新的扩充：共享模板分为个人共享和企业共享和平台共享，不仅是模板库，还能存txt/excel/csv数据源、图片，每个个人免费用户可以存10M内容，专业用户可以存100M，每个企业给300M的共享空间，如果已有内容超过这个大小的时候就不能存储新的内容；企业管理员可以设定文件夹，每个文件夹可以管理哪些企业内用户可以查看；用户可以上传和删除自己空间的内容，企业管理员可以上传删除企业内所有内容，企业内人员可以删除自己上传到企业空间的内容；平台共享只允许后台管理人员上传，所有用户都可以看到下载使用。"

## 背景与问题

| # | 现状 | 证据 |
|---|---|---|
| E1 | 桌面端「共享模板库」只是**本机 JSON**（`shared-templates.json` + blob），换机即丢失，不是云端共享 | `maxlabel/app/src/main/sharedLibrary.ts`；`TemplateLibDialog.tsx` |
| E2 | 云端只有**会员私有模板**（一人一份，仅本人可见），没有企业共享概念 | `maxlabel_label_template`；`AppLabelTemplateController` |
| E3 | 现有「平台共享模板」是**会员投稿 → 运营审核**后公开（本特性关闭投稿通道，Q115） | 009 FR-233 / FR-238；`SharedTemplateServiceImpl`；管理端「共享模板审核」页 |
| E4 | 云端**写入**一律要求「订阅当前有效」，免费登录用户不能上传 | 009 FR-219；`LabelTemplateServiceImpl.requireActiveSubscription` |
| E5 | 现有配额是全局固定的 **1000 个 / 256 MB**，不区分免费 / 专业 / 企业 | 009 FR-237；`LabelTemplateServiceImpl.MAX_TOTAL_BYTES` |
| E6 | 企业、企业成员、席位、三档版本（标准 / 专业 / 企业）已经具备 | 012 的 `maxlabel_org`、`maxlabel_org_member`、`maxlabel_org_seat`；`MemberSubscriptionServiceImpl` |
| E7 | 共享内容只能存 `.msdx` 模板，不能存数据源（txt / excel / csv）与图片 | `MaxLabelLabelTemplateDO` 的 `content` 为模板正文 |

**问题**：现有的「共享模板」只有「我的云端模板」与「平台公开模板」两极，缺少**企业内共享**，
也不能承载模板以外的内容；配额与版本、企业授权没有关系。需要把它扩成三态共享空间：
**个人空间 / 企业空间 / 平台共享**，并按版本与企业授权执行容量限制与可见范围。

## Clarifications

### Session 2026-11-05

- **Q115 与 009「会员投稿 → 运营审核」的关系？**（2026-11-05 所有者拍板）
  → **A：取消会员投稿**。平台共享只允许后台管理人员上传、修改与下架；009 Q50 的会员投稿与审核
  通道关闭。历史已通过审核并公开的条目保留，归后台管理人员继续维护（可下架或删除）。
- **Q116 企业 300 MB 从哪来？**（2026-11-05 所有者拍板）
  → **A：随企业授权有效期提供**。授权有效时企业拥有 300 MB；授权到期或企业停用后转**只读**——
  既有内容可浏览、下载与删除，不能新增上传，也不能创建/改名/删除文件夹或改可见名单；
  续费或恢复授权后恢复写入。
- **Q117 成员退出 / 被移出企业后，其上传到企业空间的内容归谁？**（2026-11-05 所有者拍板）
  → **A：留在企业**。内容不随人删除，由企业管理员继续管理；退出者立即失去对全部企业内容的访问权。
- **Q118 企业空间的使用权要不要绑定企业席位？**（2026-11-05 所有者拍板）
  → **A：仅席位成员可用**。浏览、下载、上传、删除都要求会员持有该企业未被撤销的席位分配；
  OWNER / ADMIN 不因角色豁免。席位被撤销后立即失去企业空间访问权。
  与 Q116 的对齐：授权到期后席位分配记录仍在，成员可**只读**（浏览 / 下载 / 删除）；
  **写入**（上传）另行要求企业授权当前有效。
- **Q119 删除还有内容的文件夹时，内容怎么处理？**（2026-11-05 所有者拍板）
  → **A：只能删空文件夹**。文件夹内还有内容时 MUST 拒绝删除，并提示先清空或移动到其他文件夹；
  MUST NOT 级联删除内容，MUST NOT 静默丢失。
- **Q120 企业空间能不能把内容直接放在根目录？**（2026-11-05 所有者拍板）
  → **A：不能**。企业空间的所有内容 MUST 归属于某个文件夹；根目录仅用于分组展示，
  任何角色（含管理员）MUST NOT 直接向根目录上传。
- **Q121 既有云端模板要不要计入新的个人空间容量？**（2026-11-05 所有者拍板）
  → **A：全部计入**。会员此前上传的云端模板视为个人空间内容，其体积计入个人空间已用容量；
  超过 10 MB / 100 MB 时 MUST NOT 删除，转为只读并阻止新增，删到上限以下后恢复上传。
- **Q122 个人空间的内容能不能分享给其他用户？**（2026-11-05 所有者拍板）
  → **A：不能，仅本人可见**。个人空间不提供指定用户分享或公开链接；其他用户（含同企业成员）
  与未登录用户 MUST NOT 查看、下载或删除。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 个人空间：按版本容量上传与自管理 (Priority: P1 · US50)

任何已登录用户都有**个人共享空间**，可以上传标签模板、数据源文件（txt / excel / csv）与图片，
在任意设备登录后浏览、下载、删除自己空间里的内容。容量由当前版本决定：免费（标准版）10 MB，
专业版 100 MB。容量用完后**不能再存新内容**，但已有内容仍可查看、下载与删除。

**Why this priority**：这是三态空间里唯一不依赖企业组织的能力，覆盖面最大；
同时它把「免费用户可上传」这一既有规则改变（E4）落到最小可见范围。

**Independent Test**：用一个未付费的新账号上传若干文件至接近 10 MB，再上传一个会超限的文件 →
被拒绝且提示剩余容量；删除一个文件后同一文件可成功上传；换一台设备登录仍能看到并下载。

**Acceptance Scenarios**：

1. **Given** 已登录的免费（标准版）账号，**When** 上传 9.9 MB 的内容，**Then** 成功，空间显示已用 9.9 MB / 10 MB
2. **Given** 已用 9.9 MB，**When** 再上传 1 MB 的文件，**Then** 被拒绝，提示已用、上限与剩余容量，且该文件未被保存
3. **Given** 专业版有效，**When** 上传至 100 MB，**Then** 在上限内成功；超过 100 MB 被拒绝
4. **Given** 个人空间有内容，**When** 删除其中一项，**Then** 该内容不可恢复，已用容量立即减少
5. **Given** 用户 A 的个人空间，**When** 用户 B 登录，**Then** B 看不到、也下载不了 A 的任何内容
6. **Given** 专业版到期降为免费，**When** 已用容量仍大于 10 MB，**Then** 既有内容可浏览 / 下载 / 删除，但新增上传被拒绝
7. **Given** 已在设备甲上传内容，**When** 在设备乙用同一账号登录，**Then** 能看到并下载同一份内容

---

### User Story 2 - 企业空间：成员上传、管理员统管 (Priority: P1 · US51)

持有企业席位分配（未被撤销）的成员在**企业共享空间**中浏览被授权的文件夹、上传自己的内容，并只能删除自己上传的内容；
企业管理员（OWNER / ADMIN）可以上传、删除企业空间内的**任何**内容。企业授权有效期内，
企业空间是一个**全企业共用的 300 MB 池**，所有成员的上传合计占用；用尽后任何人都不能再新增，
直到有人删除内容。

**Why this priority**：企业共享是本特性的核心增量，也是 012 企业体系缺失的一环；
没有它，会员虽然买了企业席位，共享内容仍只能在个人空间里各自为政。

**Independent Test**：管理员建一个文件夹并授权给成员甲；甲上传一个文件 → 管理员能看到并删除；
甲上传另一个文件 → 甲自己能删除，但删不掉管理员上传的文件；甲无权查看的文件夹在列表中不存在。

**Acceptance Scenarios**：

1. **Given** 企业有可用空间，**When** 成员在有权限的文件夹上传内容，**Then** 成功，上传者记为本人
2. **Given** 企业全体的上传合计已接近 300 MB，**When** 任一成员再上传超限文件，**Then** 被拒绝，提示企业已用 / 上限
3. **Given** 管理员上传的内容，**When** 成员尝试删除，**Then** 被拒绝（成员只能删自己上传的）
4. **Given** 成员自己上传的内容，**When** 本人删除，**Then** 成功且立即释放企业容量
5. **Given** 管理员角色，**When** 删除任一成员上传的内容，**Then** 成功
6. **Given** 企业空间已满，**When** 删除一项内容，**Then** 可以继续上传不超过释放量的新内容
7. **Given** 企业授权到期 / 停用，**When** 成员进入企业空间，**Then** 既有内容仍可浏览、下载与删除，但上传被拒绝

---

### User Story 3 - 企业文件夹与成员可见范围 (Priority: P2 · US52)

持有席位的企业管理员可以创建文件夹，并为**每个文件夹指定哪些企业成员可以查看**。
有权限的成员能在文件夹里看到并上传内容；无权限的成员在列表中看不到该文件夹，
直接访问也必须被拒绝。管理员可以看到全部文件夹与内容，不受可见范围限制。

**Why this priority**：没有可见范围时企业空间只是一个共享大池，无法按部门 / 项目隔离内容；
这是企业客户愿意使用共享空间的前提。它依赖 US51 的空间与上传能力，但可独立验收。

**Independent Test**：管理员建「财务」与「门店」两个文件夹，只授权甲看「财务」、乙看「门店」；
甲、乙各自登录，只能看到并被允许进入自己的文件夹。

**Acceptance Scenarios**：

1. **Given** 企业管理员，**When** 新建文件夹并勾选可见成员，**Then** 文件夹创建成功且记录可见名单
2. **Given** 文件夹仅授权成员甲，**When** 成员乙打开企业空间，**Then** 列表中没有该文件夹，也搜索不到
3. **Given** 成员乙直接请求该文件夹的内容，**Then** 被拒绝，且提示不泄露文件夹是否存在
4. **Given** 管理员把成员甲从文件夹可见名单移除，**When** 甲刷新，**Then** 该文件夹与其内容不再可见
5. **Given** 文件夹有内容，**When** 管理员删除该文件夹，**Then** 删除被拒绝，提示先清空或转移内容，内容不丢失
6. **Given** 管理员本人未在某个文件夹的可见名单里，**When** 浏览企业空间，**Then** 他仍能看到并管理该文件夹

---

### User Story 4 - 平台共享：运营统一上传，所有用户浏览下载 (Priority: P2 · US53)

**平台共享内容库**只允许后台管理人员上传、修改与下架；所有已登录用户都可以浏览、检索、
下载 / 使用。平台内容不占用任何个人或企业容量，下载得到的是副本，改动不会回写平台库。

**Why this priority**：平台共享把运营整理好的模板、数据源样例与图片统一提供给客户，
直接影响新用户第一次使用的体验；但它不依赖前面的容量与企业逻辑，可独立交付。

**Independent Test**：普通用户在界面上找不到任何上传 / 编辑 / 下架入口，直接调用也失败；
运营上传一条内容 → 用户刷新 ≤ 1 分钟可见并下载；运营下架后不再可见，已下载副本不受影响。

**Acceptance Scenarios**：

1. **Given** 后台管理人员，**When** 上传一条平台共享内容（模板 / 数据源 / 图片）并填写分类与关键词，
   **Then** 保存成功并立即对用户可见
2. **Given** 普通已登录用户，**When** 浏览平台共享，**Then** 可以按类型、分类、关键词检索并下载
3. **Given** 普通用户，**When** 尝试上传 / 修改 / 删除平台共享内容，**Then** 界面上没有入口，服务端拒绝
4. **Given** 用户下载了平台内容，**When** 本地修改并保存，**Then** 平台库与原条目不变
5. **Given** 运营下架某条内容，**When** 用户刷新，**Then** 列表中不再出现；已下载副本仍可用
6. **Given** 平台内容被大量下载，**When** 查看用户个人 / 企业容量，**Then** 平台内容的体积不计入任何配额

### Edge Cases

- **个人降档**：专业版到期变免费、个人空间已用容量超过 10 MB 时，既有内容保留且可读可删，
  只阻止新增；删除到上限以下后恢复上传能力。
- **企业席位被撤销**：立即失去企业空间访问权（浏览、下载、上传、删除全部被拒）；
  其已上传内容按 Q117 留在企业，由管理员继续管理。
- **企业授权到期但席位记录仍在**：持席成员可只读（浏览、下载、删除），上传被拒绝；
  续费或恢复授权后恢复写入。
- **管理员没有席位**：即使角色为 OWNER / ADMIN，也看不到企业空间、不能管理其内容（Q118）。
- **根目录上传**：拒绝，提示必须先选择有查看权限的文件夹（Q120）。
- **企业容量共享**：甲、乙同时上传，剩余容量只够其一时，服务端必须拒绝后到的那一笔，
  不得出现总量超过 300 MB。
- **成员退出 / 被移出**：其上传内容留在企业空间，由管理员继续管理；退出者不得再访问企业空间。
- **删除文件夹**：只能删除空文件夹；有内容时拒绝删除，并提示先清空或移动内容。
- **同名文件**：允许同名，以不同内容项区分；**不提供覆盖**，如需替换请删除旧内容后重新上传
  （避免「覆盖」语义与配额差值、审计留痕纠缠）。
- **上传中断**：未完成的上传不得占用容量，也不得在列表中留下残缺条目。
- **越权探测**：无权访问的内容统一返回「不存在或无权访问」，不得通过错误码区分「存在但无权」。
- **平台下架与正在下载**：下架不影响已经开始或已经完成的下载；之后不再展示。
- **容量统计口径**：以实际可下载内容的体积合计为准，已删除内容不计入；容量数字必须与列表一致。
- **未登录**：不存在任何共享空间入口；平台共享也只对已登录用户开放（沿用 009 Q54）。

## Requirements *(mandatory)*

### Functional Requirements

#### A. 三类空间与内容类型

- **FR-391**: 系统 MUST 提供三类互相独立的共享空间：**个人空间**、**企业空间**、**平台共享内容库**；
  同一用户 MUST 能同时使用自己的个人空间与其所属企业的企业空间，两者容量互不占用。
- **FR-392**: 共享空间 MUST 支持以下内容类型（本期封闭集合）：标签模板（`.msdx`）、纯文本（`.txt`）、
  表格数据（`.xls` / `.xlsx` / `.csv`）与图片（`.png` / `.jpg` / `.jpeg` / `.gif` / `.bmp` / `.webp`）。
  MUST NOT 接受其他扩展名，MUST NOT 接受可执行文件与脚本类文件（如 `.exe` / `.bat` / `.cmd` / `.sh` / `.js`）。
- **FR-393**: 每个内容项 MUST 记录名称、类型、字节大小、上传者、上传时间、所属空间；
  企业空间中的内容 MUST 记录所属文件夹（不允许根目录内容，Q120）。
- **FR-394**: 上传 MUST 同时校验内容类型、单文件大小上限与所属空间剩余容量；
  任一不满足 MUST 拒绝并明确说明原因，MUST NOT 产生不完整或半截的内容项。
- **FR-395**: 每个空间 MUST 向用户展示已用容量、容量上限与剩余容量，并标明当前版本
  （标准版 / 专业版 / 企业版）。
- **FR-396**: 删除内容 MUST 要求二次确认，成功后 MUST 从用户视角**不可恢复**且立即释放容量；
  服务端 MAY 保留软删标记用于审计与回滚。已下载的副本不受影响。
- **FR-397**: 模板类内容被下载 / 使用 MUST 得到独立副本；对副本的修改 MUST NOT 回写空间，
  也 MUST NOT 影响上传者或其他使用者。

#### B. 个人空间

- **FR-398**: 个人空间容量 MUST 按用户当前有效版本执行：**标准版（登录未付费）10 MB、
  专业版 100 MB**；企业版用户的个人空间按专业版 100 MB 执行，企业池另计。
- **FR-399**: 标准版（免费）用户 MUST 能上传个人空间内容，MUST NOT 再以「订阅无效」为由拒绝；
  这条**改变** 009 FR-219 中「云端写入必须订阅有效」的规则，仅对个人空间生效。
- **FR-400**: 个人空间内容 MUST 仅对本人可见，**不提供任何形式的分享**（指定用户或公开链接）；
  其他用户（含同企业成员）与未登录用户 MUST NOT 读取、下载或删除（Q122）。
- **FR-401**: 用户 MUST 能上传、浏览、检索、下载与删除自己的个人空间内容。
- **FR-402**: 版本降档导致已用容量超过新上限时，既有内容 MUST 保留且可浏览、下载、删除；
  MUST 拒绝新增上传，直到已用容量降到上限以内。
- **FR-403**: 个人空间 MUST NOT 因用户加入 / 退出企业、企业停用或企业授权变化而改变。

#### C. 企业空间

- **FR-404**: 每个企业 MUST 在**企业授权有效期内**拥有一个**全企业共用的 300 MB 共享池**，
  所有成员的上传体积合计占用；授权到期或企业停用后按 FR-415 转只读，续费或恢复授权后恢复写入（Q116）。
- **FR-405**: 企业空间 MUST 只对持有该企业**未被撤销的席位分配**的成员开放（席位门槛见 FR-429）；
  在此前提下，成员 MUST 只能看到并访问**自己被授权可见**的文件夹及其内容；
  无权限的文件夹 MUST 不在列表中展示，直接访问 MUST 被拒绝且不泄露存在性。
- **FR-406**: 企业管理员 MUST 能在**企业授权有效期内**创建、重命名与删除企业文件夹，
  并设定每个文件夹可查看的成员范围（按具体成员指定）；授权到期或企业停用后的写限制见 FR-415。
- **FR-407**: 企业管理员 MUST 能查看、上传与删除企业空间内的**任何**内容，不受文件夹可见范围限制。
- **FR-408**: 企业成员 MUST 能向自己有查看权限的文件夹上传内容；上传者固定记录为本人。
  企业空间 MUST NOT 接受根目录上传，任何角色（含管理员）都必须先选择文件夹（Q120）。
- **FR-409**: 企业成员 MUST 能删除**自己上传**的企业内容；MUST NOT 删除他人上传的内容。
  删除自己的内容 MUST 只要求席位，MUST NOT 要求当前仍对该文件夹可见（便于被取消授权后自行清理）。
- **FR-410**: 文件夹可见范围的变更 MUST 对成员生效（刷新后 ≤ 1 分钟）。
- **FR-411**: 企业空间容量用尽时 MUST 拒绝所有成员的新增上传，并提示企业已用 / 上限 / 剩余；
  既有内容仍可浏览、下载与删除。
- **FR-412**: 成员退出企业或被移出后，其上传的企业内容 MUST **留在企业空间**，由企业管理员继续管理；
  退出者 MUST 立即失去对全部企业内容的访问权（Q117）。
- **FR-413**: 文件夹 MUST 只在**为空**时允许删除；文件夹内还有内容时 MUST 拒绝删除，
  并提示先清空或把内容移到其他文件夹。MUST NOT 级联删除内容，MUST NOT 静默丢失（Q119）。
- **FR-414**: 企业空间 MUST 向企业管理员展示容量占用，以及每个文件夹的**内容数与占用字节**。
- **FR-415**: 企业授权到期或企业停用后，企业空间 MUST 拒绝任何新增上传；
  **文件夹创建 / 改名 / 删除与可见名单变更**（同属写入）MUST 一并被拒绝；
  仍持有未撤销席位分配的成员 MUST 可以浏览、下载与删除既有内容（只读，Q116 / Q118）。

#### D. 平台共享内容库

- **FR-416**: 平台共享内容 MUST 只能由**后台管理人员**上传、修改与下架；
  普通用户 MUST NOT 有相应入口，服务端 MUST 拒绝此类请求。会员投稿到平台共享的通道 MUST 关闭；
  历史已公开条目 MUST 保留，并可由后台管理人员下架或删除（Q115）。
- **FR-417**: 平台共享 MUST 对已登录用户开放浏览与检索，至少支持按内容类型、分类与关键词筛选，
  并支持下载 / 使用。
- **FR-418**: 平台共享内容 MUST NOT 占用任何个人空间或企业空间的容量。
- **FR-419**: 平台共享内容 MUST 标注内容类型与分类，便于用户判断是模板、数据源还是图片。
- **FR-420**: 下载 / 使用平台内容 MUST 得到独立副本；修改副本 MUST NOT 回写平台库。
- **FR-421**: 平台内容下架后 MUST 不再对用户展示；已下载的副本 MUST NOT 被远程删除或修改。

#### E. 权限、容量与可追溯性

- **FR-422**: 所有访问与操作权限 MUST 由服务端裁决；前端隐藏入口 MUST NOT 被当作权限控制。
- **FR-423**: 容量统计 MUST 以服务端为准：删除立即释放；并发上传超出上限时 MUST 拒绝后到者，
  MUST NOT 出现超出上限的结果。
- **FR-424**: 越权访问 MUST 统一返回「不存在或无权访问」，MUST NOT 泄露内容是否存在。
- **FR-425**: 上传、删除、文件夹可见范围变更、平台内容上下架等关键操作 MUST 可追溯
  （操作人、时间、对象）。
- **FR-426**: 容量与权限的变化（版本升降、企业授权到期 / 恢复、成员加入 / 退出、文件夹授权调整）
  MUST 在用户刷新后 ≤ 1 分钟内生效。
- **FR-427**: 单文件大小上限 MUST 由服务端统一约束并可配置；超限 MUST 拒绝并提示上限值。
- **FR-428**: 本规格中的「企业管理员」指 012 定义的 **OWNER / ADMIN** 角色；
  「企业成员」指企业内的全部在册成员。角色本身 MUST NOT 附带企业空间使用权，均以席位分配为前提。
- **FR-429**: 企业空间的浏览、下载、上传与删除 MUST 要求会员持有该企业**未被撤销的席位分配**；
  OWNER / ADMIN 不因角色豁免。上传另行要求企业授权当前有效（FR-404 / FR-415）。
  席位被撤销后 MUST 在刷新后 ≤ 1 分钟内失去企业空间访问权（Q118）。
- **FR-430**: 会员此前上传的云端模板 MUST 计入个人空间已用容量（Q121）；
  超过当前版本上限时 MUST NOT 删除，按 FR-402 的「超配额只读」规则处理，删到上限以下后恢复上传。

### Key Entities *(include if feature involves data)*

- **共享空间**：按归属分为个人（属于会员）、企业（属于企业）、平台（属于平台）；
  有固定上限（10 MB / 100 MB / 300 MB）与已用量。
- **内容项**：空间中的一条内容，含名称、类型（模板 / txt / excel / csv / 图片）、字节大小、
  上传者、上传时间、所属空间、所属文件夹（企业空间必填，无根目录内容）。
- **企业文件夹**：企业空间内的分组，含名称、所属企业、可见成员名单；由企业管理员维护。
- **平台共享条目**：由后台管理人员发布的公开内容，含类型、分类、关键词、发布人、发布时间与上下架状态。
- **容量配额**：由版本（标准 / 专业）与企业授权决定的容量上限与已用量，是上传闸门的唯一依据。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-149**: 免费用户可上传并跨设备下载不超过 10 MB 的个人内容；第 10 MB + 1 字节的上传
  100% 被拒绝，且提示包含已用、上限与剩余容量。
- **SC-150**: 专业版 100 MB 与企业 300 MB 两个上限 100% 生效；任何时刻实际存储合计不超过上限；
  删除后剩余容量立即（≤ 1 次刷新）反映正确数值。
- **SC-151**: 未授权成员对企业文件夹的列表可见数为 **0**，直接访问 100% 被拒绝；
  管理员对全部文件夹的访问成功率 100%。
- **SC-152**: 普通用户对平台共享的上传 / 修改 / 下架请求 100% 被拒绝；
  管理员发布的内容在用户刷新后 ≤ 1 分钟内可见，下架后同样 ≤ 1 分钟内不可见。
- **SC-153**: 个人空间内容对其他用户与未登录用户的可见数 **0**；越权读取 100% 被拒绝。
- **SC-154**: 成员删除他人上传的企业内容 100% 被拒绝；删除自己的内容 100% 成功；
  管理员删除任意企业内容 100% 成功。
- **SC-155**: 空间展示的已用容量与内容列表的体积合计一致（误差 0）。
- **SC-156**: 版本降档或企业授权到期后，既有内容的浏览 / 下载成功率 100%，新增上传拒绝率 100%。
- **SC-157**: 无席位或席位被撤销的成员（含 OWNER / ADMIN）对企业空间的可见数 **0**，
  浏览、上传、删除请求 100% 被拒绝；席位被撤销后 ≤ 1 分钟内生效。
- **SC-158**: 对仍有内容的文件夹发起删除，100% 被拒绝；文件夹内内容丢失数为 **0**。
- **SC-159**: 企业空间内容（含管理员上传）的文件夹归属率 100%；根目录上传请求 100% 被拒绝。
- **SC-160**: 既有云端模板 100% 计入个人空间已用容量；超限账号的存量内容删除数为 **0**，
  新增上传拒绝率 100%；删到上限以下后上传恢复率 100%。

## Assumptions

- **使用端**：共享空间的日常使用在**桌面端**（模板库 / 内容库入口）完成；平台共享内容的发布与
  企业文件夹的授权关系在**管理端**维护。门面站与小程序本期不新增共享空间页面；
  管理端已有的「共享模板审核」页随会员投稿通道关闭，仅保留对历史条目的下架 / 删除能力。
- **登录即可用**：三类空间均要求登录；个人空间登录即可使用；平台共享沿用 009 Q54 的
  「登录即可浏览，不要求有效订阅」；企业空间还要求持有席位（Q118）。
- **免费用户可直接写入**：按本次描述，免费（标准版）用户拥有 10 MB 写入能力；
  这取代 009 FR-219 对个人空间写入的订阅要求，但不改变 009 规则里「删除/取消共享属于数据处置权」的口径。
- **既有云端模板并入个人空间**：会员此前上传的私有云端模板视为个人空间内容，继续对本人可见，
  其体积计入个人空间已用容量；不因超过新上限而被删除（Q121）。
- **删除的存储语义**：删除对用户不可恢复，但服务端 MAY 保留软删标记与对象存储文件用于审计；
  用户看不到、也无法恢复已删内容。
- **企业容量不可叠加**：本期企业固定 300 MB，不提供加购；同一用户同时属于个人与企业时，
  两个空间的容量分别计算。企业版用户的个人空间仍按专业版 100 MB 计。
- **企业空间按席位开放**：浏览、下载、上传与删除都要求成员持有该企业未被撤销的席位分配；
  OWNER / ADMIN 同样需要席位（Q118），与 012「角色不自动附带权益」的口径一致。
  授权到期后席位记录仍在，持席成员可只读；撤销席位则立即失去访问。
- **同企业单一归属**：沿用 012 的「一人同一时刻只属于一个企业」，因此一个用户同一时刻
  最多只有一个企业空间。
- **单文件上限**：默认沿用 16 MB 的单文件上限（现有模板约束），并在服务端可配置；超过上限的文件
  不因空间还有剩余容量而被接受。
- **内容清洗**：模板类内容沿用 009 既有的服务端清洗（剥离数据库口令、设备口令与业务数据行）；
  数据源与图片不执行模板清洗，但不得携带可执行内容。
- **不涉及计费变更**：本特性不新增商品、不改动定价与订阅规则；容量差异只跟随既有版本与企业授权。
- **平台共享不含会员投稿**：平台共享由后台管理人员直接上传与维护；009 的会员投稿与审核通道关闭，
  历史已公开条目保留（Q115）。

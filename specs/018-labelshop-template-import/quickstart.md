> 目标：在不访问真实 LabelShop 的情况下先跑通自动化测试；再用一个有权限的测试账号做一次端到端手工验收。
> 详细口径见 [spec.md](./spec.md)、[data-model.md](./data-model.md)、[contracts/admin-api.md](./contracts/admin-api.md)、
> [contracts/labelshop-upstream.md](./contracts/labelshop-upstream.md)。

## 0. 前置

- MySQL 已执行 `yudao-cloud/sql/mysql/038-labelshop-template-import.sql`；
- 后端 `yudao-server` 可启动（48080）；管理端可启动（HTTP 或 HTTPS 入口均可）；
- 准备一个测试企业：有 OWNER、≥1 个有效席位、授权批次未过期；
- 准备一个 LabelShop 测试账号（含「我的模板库 / 组模板库 / 企业组织模板」各若干条；
  公共 / 用户模板库可忽略）；
- 桌面端 `maxlabel` 可构建；

## 1. 自动化测试（先红后绿）

```bash
# 后端（先跑新增测试，确认失败；再实现）
cd yudao-cloud
mvn -pl yudao-module-member/yudao-module-member-server -am test -Dtest='*Labelshop*' -Dsurefire.failIfNoSpecifiedTests=false

# 管理端（script 名为 test）
cd yudao-cloud/yudao-ui/yudao-ui-admin-vue3
npm test -- LabelshopImportDialog OrgDetail

# 桌面端（纯函数 + 类型检查）
cd /d/workspace/maxlabel/app
npm run typecheck
npm run test:unit -- msdx
npm run test:dom
```

> 个人会员代导（Q145）的自动化覆盖在 `LabelshopSourceEnumeratorTest`（只读我的模板库）、
> `LabelshopImportRunTaskTest`（个人空间落点、无企业文件夹）、`LabelshopImportServiceImplTest`
> （会员校验 / 个人 precheck）与 `LabelshopImportDialog.spec.ts`（会员模式）中。

> Maven 环境坑（项目既有）：不给 `-am` 会读到本地仓库里过期的兄弟模块 jar，成片
> `NoClassDefFound`；给了 `-am` 又可能被 IDE 写进 `target/classes` 的脏 class 挡住，
> 成片 `VerifyError/ClassFormatError` 且指向你没改过的模块。遇到后者先清 `target/classes`。

**必须覆盖**：

- 来源映射（`Own_Type=12/13/1`；14 与其他不读取）；
- Exec 签名 / OSS 签名 / UA / mid（纯函数）；
- 幂等：第二次导入新增 0、跳过 = 第一次成功；
- 容量例外：超限仍写入、`used_bytes` 正确、常规上传被拒绝；
- 所有者归属：企业内容 `owner_member_id=OWNER`；普通成员不可删；
- 文件夹：每次新建 `<时间>导入`、ACL = 导入开始时有效席位、既有文件夹 ACL 改动 0；
- 会话失效：重登 1 次并继续；再次失效中止且已写入保留；
- 控制器：precheck / start / task / latest / items；start 请求体不进入访问日志；
- 管理端对话框：precheck 阻断、请求体、轮询、失败清单、HTTP 下可用；
- 桌面端：`cloudContentKind` 区分 `.lsdx` / 归档 JSON / 普通 JSON；
- 模板外链图片（Q148~Q151）：下载并内嵌、写入图片内容、同图去重、失败不阻断（`LabelshopImageImporterTest`）。

## 4. 正常导入（样例账号）

1. 打开企业详情 → 成员与席位 → 点击「导入历史模板」；
2. precheck 显示：OWNER、文件夹名 `yyyyMMddHHmmss导入`、席位数、个人/企业容量；
3. 输入测试账号密码（可用**非 OWNER** 的经授权账号，验证 Q139 / SC-187），勾选授权确认，开始；
4. 观察进度：
   - 提交后 ≤10 秒看到任务已开始与进度界面（SC-174）；
   - 阶段 `LIST`：显示「正在读取模板列表」；
   - 阶段 `IMPORT`：`processed/total` 递增；
   - 终态 `2 已完成`：汇总显示成功 / 跳过 / 失败、个人/企业字节、按来源库分布；
   - **刷新或重开企业详情页**：仍能看到当前状态/最终结果（SC-180）；
5. 预期（样例账号）：个人空间来自「我的模板库」、企业空间来自「组模板库 + 企业/组织模板」，
   失败 0；具体条数以测试账号为准，但**不得**包含公共模板库（2019 条）的任何条目。
   2026-11-13 修正分类树参数后，旧记录里的 44 / 194 / 7 仅作参考；**必须按来源库语义核对**：
   个人空间只能出现「我的模板库」内容，企业空间只能出现组模板库与企业/组织内容。
   该账号的 2 条空模板（`新标签模板1`、`实惠装条码`）属于被排除的公共模板库，**不应**出现在结果中；
   如需验证失败清单，请在测试环境注入一条空正文或断网。
   使用非 OWNER 的经授权账号也应得到相同结果（SC-187）。

## 4.1 个人会员代导（Q145 / SC-192）

1. 管理端 → 会员管理 → 会员用户 → 任一**个人会员**详情 → 「个人空间」页签 → 点击「导入历史模板」；
2. precheck 显示：会员昵称 / 手机号掩码、个人空间用量与配额；**不显示**企业、文件夹、席位与企业空间；
3. 输入该会员的历史系统账号密码并勾选授权 → 开始；
4. 预期：
   - 只读取「我的模板库」（`Own_Type=12`），组模板库 / 企业组织模板读取数为 0；
   - 内容全部写入该会员的 016 个人空间，企业空间新增 0、新建企业文件夹 0；
   - **`Own_Type=0` 云端模板全部转为可编辑 `.lsdx`**；转换失败只出现在失败清单，不产生 `.json` 回退；
   - **个人空间按来源分类路径出现多层文件夹**（如「我的模板」「LabelShop5」「锡珠钢球 80 50」），
     同名路径重复导入复用，不重复建树；
   - 容量口径与企业导入一致：超限仍完成，之后常规上传按 016 超配额只读；
   - 同一会员重复导入：第二次新建内容 0、跳过 = 第一次成功；
5. 导入完成后，管理端「个人空间」页签刷新即应看到**左侧树形文件夹 + 右侧内容列表**；
   点击文件夹切换筛选（「全部内容」/「默认目录」/具体文件夹），列表保留「文件夹」列；
6. 会员登录桌面端 → 「共享空间 → 个人空间」：可看到分类文件夹树，能新建 / 改名 / 移动 / 删除
   空文件夹，移动到自身或子级被拒绝；文件夹内 `.lsdx` 可加载/打开；
7. C 端（门面站 / 桌面端）不应出现该**导入**入口（个人文件夹 CRUD 属桌面端共享空间正常能力）。

## 4.2 模板外链图片（Q148~Q151，2026-11-26）

1. 准备一条含 `<picture type="1" file="labelshop:\\codingv\...">` 的 `.lsdx`（例：`王颖—稀土.lsdx`，
   4 张外链图 + 1 张原生 `img=` 内嵌图），导入到企业或个人空间；
2. 预期：
   - 模板在桌面端打开时，**5 张图片全部显示**，不再提示「引用的文件当前无法读取」；
   - 模板所在文件夹里新增对应的图片内容（类型「图片」），名称取 `pname`（如 `20071211.png`）；
     管理端/桌面端的「尺寸」列显示 `srcwidth`/`srcheight` 换算的 mm（如 23.37 × 21.59 mm），不是「—」；
   - 任务详情 `errorMessage` 里不出现图片失败；若注入 404，则模板仍成功、任务结果显示图片名与原因；
   - 同一图片被同任务多个模板引用时，文件夹里只有一条图片内容（下载次数 ≤ 1）；
   - 图片字节计入空间已用容量，但导入本身在超配额时仍完成；
3. 注意：图片 OSS 上目前是缩略图（约 100dpi），打印清晰度不作为本期验收项（Q149）。

## 5. 落点与权限

1. 用 OWNER 登录桌面端 → 共享空间 → 个人空间（个人云空间）：应看到 44 条 `.lsdx`，可加载/打开；
2. 用持席成员登录桌面端 → 企业空间：应看到本次新建的 `<时间>导入` 文件夹，内有 201 条；
3. 同企业另一个未持席成员 → 企业空间不可用（016 席位门槛）；直接请求被拒绝；
4. 管理员未持席 → 也看不到企业空间（016 Q118）；
5. 既有文件夹的可见名单未被改动（对比导入前后）；**导入后新增一个席位**，确认新成员
   没有被自动加入本次文件夹的可见名单（SC-188）；
6. 普通成员不能删除导入内容；OWNER / ADMIN 可以删除（SC-190）；
7. 任务详情的操作人与执行导入的后台账号一致（SC-190）。

## 6. 桌面端可用性

1. 个人空间加载一条 `.lsdx` → 可直接打开并编辑（复用 `importLsdx`）；**另存为**本地 `.lsdx`
   后文件可再次打开（SC-183）；
2. 企业空间加载一条 `.lsdx` → 可直接打开；另存为本地 `.lsdx`；
3. 企业/组织私有 JSON → 显示「旧版归档，暂不可直接编辑」，提供「另存为」；
4. 归档 JSON 另存后文件内容与源端一致（逐字节）；抽查一条**不含外链图片**的 `.lsdx` 另存文件与源端正文
   逐字节一致；含外链图片的模板允许图片引用改写造成的差异（SC-186 / SC-195）；
5. 个人云模板列表里的导入条目缩略图为空白轮廓（016 无缩略图字段，本期不迁移；属预期）；
6. 单条超过 16 MB 的模板 → 明细失败（`超过 16 MB`），不写入，其余条目继续；
7. **全量可打开性（SC-183）**：用桌面端测试脚本遍历导出目录的全部 `.lsdx`，逐一调用
   `importLsdx`；失败数必须为 0（如有失败，记录文件名与原因并回退排查）。

## 7. 重复导入

1. 同一账号再次导入；
2. 预期：新建**第二个** `<时间>导入` 文件夹；首次成功的模板全部 `跳过`，新增内容 0；
3. 若第一次有失败项（测试环境注入空正文/断网），第二次仍失败并出现在失败清单。

---

## 8. 容量例外与写入闸门（Q136 / SC-182 / SC-191）

1. 在测试个人空间接近上限时执行导入；
2. 预期：导入仍完成，不因容量被拦截；任务详情 `personalExceeded=true`；
3. 导入后：
   - OWNER 的常规上传被拒绝（016 超配额只读）；
   - 删除若干内容后，常规上传恢复；
   - 已用容量与内容列表体积合计一致（误差 0）。
4. **中途停用 / 到期**：导入进行中把企业停用（或使唯一授权批次过期）→ 后续**每一条**新增写入停止，
   任务 `FAILED`、`errorMessage` 记录原因，已写入内容保留（SC-182）；
5. **停用 / 无授权发起**：企业停用或授权过期时发起 → 整批拒绝，个人 / 企业新增内容项均为 0（SC-191）。

## 9. 安全

1. 错误密码 → `MEMBER_LABELSHOP_LOGIN_FAILED`，任务 `FAILED`，无内容项，**不留下空文件夹**；
2. 检查 `infra_api_access_log`：`start` 无请求体（`requestEnable=false`）；
3. 检查 `maxlabel_labelshop_import_task`：只有 `source_account_masked`，无密码 / token；
4. 检查应用日志：无密码明文、无 `cvstoken` / `cvsuid`；
5. 对 LabelShop 的请求：只出现 4 个只读过程；无 Add/Update/Delete/Save。

---

## 10. 会话失效（可用测试替身）

1. 在测试环境把 `LabelshopClient` 的 token 置为失效（或注入一个一次性的 401 响应）；
2. 预期：自动重登 1 次并从断点继续；再次失效 → 任务 `FAILED`，已写入内容保留，
   失败清单包含未处理项；
3. 重登次数 ≤ 1（不得每条失败重登）。

---

## 11. 回滚

1. 菜单/按钮 `status=1` 或 `deleted=1` → 前端入口消失，接口 403；
2. 已导入内容保留在 016 空间，不自动删除；
3. 2 张导入表保留供审计；如需彻底回滚，先确认无进行中任务，再 drop；
4. 桌面端回退 `onCloudLoad` 分发即可，不影响既有 `.msdx` / 裸 JSON；
5. 图片导入（2026-11-26）回滚：回退后端即可，无 SQL；已写入的图片是普通 016 图片内容，
   可由用户删除；已内嵌图片的模板正文**不会自动还原**为 `labelshop:` 链接。

## 12. 明确不验证

- LabelShop 未来的协议 / 证书 / 接口变更；
- 真实 LabelShop 账号被厂商锁定的申诉链路；
- 模板在真机上的打印效果；
- 多实例部署下的任务恢复（本期单实例；`heartbeat_time` 已预留）；
- 缩略图迁移（016 无字段，本期不承诺）；
- 外链图片的**打印清晰度**（2026-11-26：当前取 OSS 缩略图，约 100dpi；原图地址不在本期）；
- 真实 STS / 某公司列表 / 分类树故障（用测试替身模拟，见 T016 / T043）；
- **真实厂商导出的 `.lsdx` 自动化样本**：仓库只保留脱敏样例 `fixtures/lsdx/minimal.lsdx`；
  真实导出文件含业务数据、不便入库。SC-183 的「全量可打开（失败 0）」由 T053 用导出目录逐文件
  手工验证，不在自动化中固化真实样本（2026-11-13 确认）。
